## 它是什么
Meetily 是一个桌面端 AI 会议助手，可捕获系统音频并**完全在本地完成实时转录、说话人分离和智能摘要**。它基于 Rust 构建，利用 Whisper/Parakeet 实现转录，并统一对接 Ollama（本地大模型）或兼容 OpenAI 的 API 生成摘要。所有数据永不上传云端。

## 为什么火
- **隐私焦虑刚需**：近年云会议工具频繁爆出数据滥用、存储不合规等问题，企业（尤其法律、医疗、金融）急需无须信任第三方的录音转写方案。
- **全离线能力稀缺**：多数方案要么依赖云端 API（如 Otter.ai），要么转录与摘要分离；Meetily 一次安装即可实现从捕获到总结的完整离线管道。
- **开源+自托管生态**：MIT 协议可自由修改，避免供应商锁定，吸引注重自主权的开发者。

## 技术栈
- **桌面壳**：Tauri（Rust 后端 + 前端 WebView）
- **前端 UI**：Next.js (React)
- **语音识别**：Whisper.cpp / Parakeet 模型，支持通过 GPU 加速（Metal、CUDA、Vulkan）获得 4 倍以上实时转录速度
- **摘要引擎**：本地首选 Ollama，也可切换至 Claude、Groq、OpenRouter 等
- **音频处理**：Rust 实现的麦克风+系统音频同时捕获、智能混音

## 核心能力
1. **实时转录**：会议进行中即可看到滚动文字稿，延迟低。
2. **说话人分离**：自动区分不同发言者（PRO 版增强中）。
3. **AI 摘要**：会议结束后一键生成摘要，支持多语言（新版本加入 Qwen 3.5 内置模型）。
4. **音频导入增强**：支持上传已有录音文件重新转录或优化。
5. **完全离线**：零网络请求，录音、转录文本、模型全部留存在本机。

## 适用场景
- **高合规性行业会议**：律师-客户会面、医疗病例讨论、国防项目沟通。
- **远程团队内部站会**：不希望商业对话暴露给第三方 SaaS。
- **极客个人工作流**：搭配本地大模型（Ollama）形成无云办公闭环。

## 同类对比
| 工具 | 隐私策略 | 离线支持 | 一体化程度 | 开源 |
|------|----------|----------|------------|------|
| Otter.ai / Fireflies | 云端处理，非自控 | 否 | 高（转录→摘要→搜索） | 否 |
| Buzz (Whisper） | 本地转录，但无内置摘要 | 是 | 低 | 是 |
| MacWhisper | 本地，仅转录 | 是 | 低 | 部分是 |
| **Meetily** | **全本地，零数据外泄** | **是** | **高（转录+分离+摘要+编辑）** | **是** |
Meetily 的差异化在于将“录音-转录-摘要”整合为一条龙本地应用，且提供类 SaaS 的界面体验。
