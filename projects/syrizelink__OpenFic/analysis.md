## 它是什么
OpenFic 是一个面向小说作者的 AI Native 写作工具，提供跨平台的编辑器和可深度配置的 Agent 系统，强调人机协同而非一键式生成。

## 为什么火
- 细分领域精准：专为小说创作设计，内置设定、角色、章节管理。
- 数据主权：所有项目本地持久化，零云依赖，满足隐私敏感用户。
- 成本控制：多层上下文管理、智能压缩、缓存机制，降低 API 调用开销。
- 可定制性：允许用户自由修改 Prompt，构建个性化写作工作流。

## 技术栈
- 后端：Python 3.12+
- 部署：Docker、pip、桌面应用（多平台）
- 核心能力：语义化检索（向量 RAG）、流式交互、多模型适配
- 界面：响应式 UI，适配桌面、移动端、浏览器

## 核心能力
- **写作优化编辑器**：专为码字体验设计
- **全面模型支持**：集成多家模型提供商，兼容 OpenAI API 格式
- **人机协同**：Agent 可辅助发散思路、校验前后文、补全细节
- **语义检索**：基于向量的 RAG，在百万字级别项目中高效检索过往内容
- **工作流引擎**：高度可配置的 Agent 工作流，按需调整 Prompt

## 适用场景
适合正在撰写中长篇、需要维护复杂世界观和上下文的小说作者，以及希望本地化部署、自定义写作流程的极客用户。不适合短文案或一键式小说生成需求。

## 同类对比
相比通用 AI 写作工具，OpenFic 更聚焦小说创作的长期上下文管理和 Agent 可定制性；类似工具如 SillyTavern 更侧重角色扮演，而 OpenFic 以项目管理为核心。
