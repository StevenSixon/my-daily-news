## 它是什么
基于大模型的A股/港股/美股/日股/韩股/台股自选股智能分析系统，自动生成决策仪表盘并通过企业微信、飞书、Telegram等渠道推送。

## 为什么火
GitHub Actions零成本定时运行、无需服务器；覆盖六大市场新闻/行情/技术指标；Web工作台提供Agent策略问股、回测、持仓管理；文档详尽，社区活跃。

## 技术栈
Python 3.10+，FastAPI，多种LLM后端（Anspire、Gemini、OpenAI、Claude、Ollama等），行情数据源（AkShare、Tushare、yfinance等），新闻搜索（SerpAPI、Tavily等），通知渠道（企业微信、飞书、Telegram、Discord等）。

## 核心能力
- 每日自动分析自选股并输出评分/趋势/买卖点位/风险警报/催化因素
- 多市场行情、K线、技术指标、新闻/公告聚合
- Web/桌面工作台：手动分析、历史报告、回测、持仓管理
- Agent多轮策略问股（均线、缠论、波浪等15种策略）
- 智能导入（图片/CSV/Excel/剪贴板）
- 多种部署方式：GitHub Actions、Docker、本地、云服务器

## 适用场景
个人投资者每日快速复盘；量化初学者搭建自动报告系统；小型团队投研辅助；对多市场基本面+舆情监控有需求的用户。

## 同类对比
对比单一市场工具或纯数据接口，本项目集成度更高，LLM生成可读报告并多通道推送；对比商业产品，其开源免费、可自托管、定制灵活。
