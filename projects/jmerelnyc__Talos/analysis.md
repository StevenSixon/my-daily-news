## 它是什么
Talos 是一个去中心化的推理网络，你将自己的 GPU 贡献出来运行开源模型（通过 Ollama），完成网络中分发来的推理任务，并根据贡献量获取收益。这个仓库是 worker 客户端，安装后配对账户即可接入网络。

## 为什么火
项目刚发布即获 720 星，因为抓住了两个需求：有 GPU 但利用率不高的个人/小团队想赚点外快；以及需要灵活、低成本推理服务的开发者。它把“共享闲置算力”的概念从带宽扩展到了 AI 推理，且直接集成 Ollama，模型生态现成可用。

## 技术栈
- Python 3.9+ 客户端
- Ollama 作为模型推理后端
- WebSocket 与服务器通信（任务下发、心跳上报）
- 本地仪表板（127.0.0.1:8674）用于监控
- 账户配对采用设备码机制

## 核心能力
- 与 Talos 账户配对，无需暴露敏感信息
- 可调节分配比例（--allocation 0.5），控制推理并发/占空比
- 本地 Web 仪表板实时显示状态与调整滑块
- 支持 NVIDIA GPU 检测，也能回退到 CPU
- 底层 WebSocket 长连接，确保低延迟任务接收

## 适用场景
- 拥有 NVIDIA GPU 的个人开发者，闲置时投入推理网络赚取收入
- 小型渲染/计算农场，将部分算力租借给推理任务
- 对 AI 有好奇的极客，验证“共享推理”模式的可行性

## 同类对比
与 Grass（分享带宽）不同，它分享的是 GPU 算力；与 Salad 等项目相比，它直接使用 Ollama，无需定制容器镜像，模型选择更自由（任何 Ollama 支持的模型）。与 Vast.ai 等算力市场相比，它更偏向被动、零运维的“贡献并赚取”模式。
