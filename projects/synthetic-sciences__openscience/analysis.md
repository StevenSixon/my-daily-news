## 它是什么
OpenScience 是一个面向科学研究的开源 AI 工作台。用户只需设定一个研究目标，Agent 就能自主完成整个科研循环：检索并阅读相关论文，提出假说，编写并运行代码，执行实验，分析结果，最后撰写研究报告。它通过浏览器界面提供完整的 IDE 体验，支持文件树、编辑器、终端以及分子/基因组等科学数据的可视化渲染。

## 为什么火
近期 AI for Science 领域爆火，但多数工具仅覆盖科研链条的单一环节（如文献总结或代码补全）。OpenScience 是首个将文献调研、实验计算、论文撰写全流程打通的本地化开源方案，赋予科学家完全的控制权和数据隐私。其模型无关的设计允许接入任何前沿或开源模型，不锁定厂商，契合极客追求开放生态的心态。

## 技术栈
- **运行时**: Bun，包管理采用 npm
- **语言**: TypeScript 全栈
- **架构**: 本地服务器 + 浏览器工作区 UI
- **前端**: 自研工作台界面，集成 LSP、MCP 服务器
- **后端 CLI**: 提供 CLI、服务器、提供者集成、会话与技能管理
- **工具层**: 290+ 科研技能，30+ 科学数据库（UniProt, PDB, arXiv 等），支持 MCP 插件扩展
- **分发**: npm 全局包、平台二进制（GitHub Releases）

## 核心能力
1. **全循环研究代理**：单一会话中完成文献综述、假说、编码、实验、分析、撰写。
2. **多专业代理**：内置 research、biology、physics、ml 等专家代理，支持代码审查、文献综述子代理。
3. **海量技能**：覆盖 DeepSpeed/PEFT 训练、评估、数据集处理、分子/临床生物学、化学信息学、论文 LaTeX、图形绘制、云算力（Modal、Tinker 等）。
4. **科学数据库互联**：直接查询 UniProt、PDB、Ensembl、ChEMBL、PubChem、arXiv、Semantic Scholar 等，代理可直接操作。
5. **可扩展性**：支持 LSP 集成、MCP 服务器、插件、自定义代理和命令，并提供 TypeScript SDK。
6. **隐私与自由**：API 密钥存储在本地，请求直连提供商，无账号要求，可与 Atlas 托管平台按需结合。

## 适用场景
- 计算科学家（ML/生物/物理/化学）需要快速验证一个想法，从文献调研到初步实验代码一气呵成。
- 团队希望有一个自托管的 AI 助手，处理科研项目的日常工作，同时保证数据不上传第三方。
- 探索“AI 科学家”概念的研究者，利用其模块化设计自定义代理、添加专业工具。

## 同类对比
- **谷歌 AI co-scientist**：封闭，需要邀请制，不能本地化部署。OpenScience 开源且可自托管，更灵活。
- **Elicit、Consensus**：聚焦文献检索和总结，不生成代码、不运行实验。OpenScience 是端到端的解决方案。
- **Copilot / Cody**：代码补全为主，缺乏实验设计与科学数据库集成。OpenScience 内置科研上下文。
