## 它是什么
OpenScience 是一个开源的 AI 科研工作台，用户设定研究目标后，它能自动完成文献综述、假设提出、编码、实验、分析及报告撰写。

## 为什么火
- 完整的科研自动化闭环，减少重复性探索工作量。
- 模型无关，支持 Anthropic/OpenAI/Google 等主流厂商，使用自有 API 密钥，无需账户。
- 内置 290+ 技能（训练、评估、分子与临床生物学、化学信息学、LaTeX 等），并提供 Uniprot、PDB、arXiv 等 30+ 科学数据库的查询工具。
- 提供浏览器工作区，含文件树、编辑器、终端和可视化渲染（分子、结构、基因组、图表）。
- 支持自定义 Agent、插件、MCP 服务器和 TypeScript SDK，可扩展性强。

## 技术栈
- CLI 与后端服务器：TypeScript (Bun 运行时)
- 前端：浏览器工作区 UI
- 工具层：LSP 集成、MCP 服务器、技能系统、科学数据库连接器
- 模型路由：按请求动态切换提供商

## 核心能力
- 多专业 Agent：默认 research，另有 biology、physics、ml 专家，配套 critique 和文献审阅子 Agent
- 真实计算：可通过云服务（Modal、Tinker 等）运行实验
- 只读计划模式，保障实验安全
- 会话、产物和来源记录存储在磁盘，可分享
- 配置灵活：全局配置 (`~/.config/openscience/`)，项目级配置 (`openscience.json` 或 `.openscience/`)

## 适用场景
- 研究人员快速验证新想法，自动化文献调研和基线实验
- 交叉学科探索（如用 ML 方法分析生物学数据）
- 个人开发者或小团队自托管科研助手，不依赖外部平台
- 需要安全、本地运行、使用自有模型或 API 密钥的企业环境

## 同类对比
与 LangChain、AutoGPT 等通用 Agent 框架相比，OpenScience 专精科研领域，自带海量科研技能和科学数据库连接；与闭源科研助手相比，它完全开源，可本地部署、私有化使用，且不锁定模型提供商。
