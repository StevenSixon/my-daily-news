## 它是什么
OpenScience 是一个面向科学研究的开源 AI 工作台。用户设定一个研究目标后，它会自动完成文献检索、假设形成、代码编写、实验执行、结果分析和报告撰写，形成完整的科研循环。它通过浏览器提供完整的开发环境，支持文件树、终端、代码编辑器，并内置 290+ 技能和数十个科学数据库接口。

## 为什么火
项目上线即获大量关注，核心在于它把“自主科研 Agent”从概念变成可本地运行的开源工具。它强调模型无关和自托管，研究者可使用自己的 API 密钥，数据不离开机器，契合学术界的隐私与定制化需求。内置的专业技能（ML 训练、分子生物学、化学信息学等）和 Atlas 可选托管平台，进一步降低了使用门槛。

## 技术栈
- **语言**：TypeScript
- **运行时**：Bun（开发构建）、Node.js（分发）
- **架构**：本地服务器 + 浏览器前端；CLI 作为入口，前端为 React 工作区
- **集成**：Anthropic, OpenAI, Google 等模型提供者；UniProt, PDB, arXiv 等 30+ 科学数据库；LSP 语言服务；MCP 服务器
- **分发**：npm 包及平台二进制文件

## 核心能力
- **全自动研究循环**：从目标到报告一气呵成
- **多领域**：预置 research、biology、physics、ml 四个专业 Agent
- **丰富的技能库**：涵盖模型训练、评估、数据处理、分子/临床生物学分析、论文写作、图表生成、云端计算等
- **科学数据库直连**：直接查询 UniProt, ChEMBL, arXiv 等
- **完整工作区**：浏览器内的编辑器、终端、文件管理器及分子/基因组内联渲染
- **可扩展**：支持 LSP、MCP 插件、自定义 Agent、TypeScript SDK

## 适用场景
- 科研人员自动化探索文献、验证假设、运行计算实验
- 机器学习工程师快速训练模型、对比评估
- 化学/生物学研究者进行数据库查询与模拟分析
- 教育领域：作为科研方法与自动化的教学工具

## 同类对比
与 GPT‑Researcher 等自动研究工具相比，OpenScience 更侧重于科学实验的计算执行端，而非仅仅生成综述。它原生集成了代码运行环境和大量科学数据源，并支持任意 API 模型，避免了厂商锁定。其“技能”系统提供了细粒度的可复用操作，而不仅仅是 LLM 自由发挥。

## 版本动态

## ℹ️ 置信度与信息盲区

- 置信度：**high**
- 信息盲区：无性能基准（如文献检索准确性、实验成功率）或真实案例；本地模型（如通过 Ollama）的集成方式未详细说明；Demo 免费模型的速度、能力边界未描述；Agent 安全风险除容器隔离外无具体防护措施说明；与其他科研 AI 助手（如 PaperQA2）的量化对比缺失
