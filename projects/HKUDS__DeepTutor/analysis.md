## 它是什么
DeepTutor 是一个基于多智能体架构的终身个性化AI辅导平台，通过大语言模型与检索增强生成 (RAG) 结合，实现类似人类导师的交互式学习体验。用户可构建知识库、配置不同的代理伙伴 (Partners)，并通过聊天、深度研究、测验等模块进行学习。

## 为什么火
仓库 Star 数接近 3 万，更新极其高频（几乎每日发布）。其亮点在于将教育领域的复杂需求拆解为可插拔的代理与知识管理组件，并且与主流即时通讯工具 (Slack, Feishu 等) 深度打通，能够快速嵌入现有工作流。

## 技术栈
后端 Python 3.11+，前端 Next.js 16，集成 LlamaIndex/LightRAG 等多套 RAG 引擎，支持 OpenAI 兼容接口、Pydantic 结构化输出。底层包含 FAISS 向量数据库、PocketBase 等存储方案，并通过 Docker 容器化交付。

## 核心能力
- **多模式交互**：聊天、深度研究 (Deep Research)、求解模式、测验卡片、可视化动画
- **知识管理**：知识库 (KB) 上传与文档解析，支持 GraphRAG、PageIndex、LightRAG 等多检索后端
- **多代理协作**：用户可创建并指派不同人格、知识库和技能的代理伙伴，支持私有多轮记忆
- **多通道集成**：除 Web 界面外，正式支持 Slack、飞书、Mattermost、Matrix、Zulip 等 15 个即时通讯通道
- **社区技能生态**：可从 ClawHub 安装社区技能，并具备 CLI 管理工具

## 适用场景
- 个人自建个性化学习助手，长期跟踪学习进度
- 教育机构内部部署智能辅导机器人，辅助教学与答疑
- 开发者基于此平台构建垂直领域的知识型 Agent 应用

## 同类对比
相较于通用型 ChatBot 框架 (如 LangChain、AutoGPT)，DeepTutor 聚焦教育场景，内置了学习路径规划、知识图谱检索、测验生成等教育专属模块。相较于专有AI导师产品 (如 Khanmigo)，其完全开源且可自托管，拥有更灵活定制能力和社区技能交换机制。
