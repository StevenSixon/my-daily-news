## 它是什么
Project AIRI 是一个受 Neuro-sama 启发的开源项目，旨在打造可自托管、完全属于用户的“数字生命”容器。它不仅提供文本聊天，还支持实时语音对话、在 Minecraft 和 Factorio 等游戏中与用户互动，通过 Live2D 或 VRM 模型呈现二次元虚拟形象，力图实现全能型 AI 伴侣。

## 为什么火
Neuro-sama 作为最知名的 AI VTuber 之一，其能力令许多人向往，但源码未公开且无法离线交互。AIRI 填补了这一空白——以 MIT 开源，任何人都可以部署自己的“灵魂容器”，在 Discord、桌面或浏览器中与 AI 角色进行多模态互动。社区高度活跃（44k Star），衍生出多个子项目，并正在快速迭代游戏能力和多平台体验。

## 技术栈
- 主语言：TypeScript
- 桌面端：Electron，支持 Windows / macOS / Linux
- 前端 / Web 端：基于 VitePress 的文档站，Web 客户端支持移动端响应式
- 模型支持：Live2D（角色卡片导入导出支持.zip 打包）和 VRM
- 语音：实时语音输入与播放，麦克风权限管理
- 游戏集成：Minecraft、Factorio（包含独立的 airi-factorio 子项目）
- 后端 / AI 引擎细节未在 README 中详述，但从 DevLog 推断包含 RAG、记忆系统、嵌入式数据库等实验性模块。

## 核心能力
- **实时语音聊天**：桌面版支持直接语音输入，自动缓冲并避免回声。
- **游戏互动**：能在 Minecraft 和 Factorio 中与玩家协作或观察，甚至进行纯视觉游戏理解。
- **角色卡片系统**：可导入/导出包含 Live2D 模型资源的角色包，支持非 ASCII 文件名。
- **多平台交付**：Windows / macOS / Linux 原生应用、Web 端、移动端 PWA，并提供 winget、Scoop、Homebrew 等包管理器安装。
- **自托管与隐私**：完全由用户掌控，数据不经过第三方，支持离线/本地运行潜力。
- **扩展与社区生态**：拥有独立的 @proj-airi 组织维护 RAG、记忆系统、图标、Live2D 工具等子模块。

## 适用场景
- 想拥有类似 Neuro-sama 的 AI 伴侣，且需要自托管以确保隐私和长期可用性。
- 二次元角色扮演爱好者，希望角色能看自己玩游戏、聊天并实时互动。
- AI 研究者/开发者探索多模态代理与游戏环境的结合。
- 寻找可深度定制、二次开发的 VTuber 或数字人框架的团队。

## 同类对比
- **Character.ai / JanitorAI**：以文本为中心的聊天平台，无语音、无游戏交互。
- **SillyTavern**：强大本地/自托管 AI 角色扮演前端，但无原生游戏集成和实时语音。
- **其他 AI VTuber 开源项目**：多数仅实现直播推流或简单对话，AIRI 独特点在于深度游戏控制、跨平台桌面应用和“数字生命”的完整愿景。
