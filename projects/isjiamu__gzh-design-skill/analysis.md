## 它是什么
面向 AI Agent（Claude Code、Codex、Cursor 等）的公众号排版技能包。输入 Markdown，输出可直接粘贴进微信公众号编辑器的 HTML——所有样式内联，规避平台过滤规则，实现“粘进去不掉格式”。内置 6 套精选主题（摸鱼绿、红白、石墨极简、留白禅意、摸鱼票据、橄榄手记），并支持用一句话或参考图由 Agent 生成自定义主题。项目以 AGPL-3.0 开源，由“甲木 × 摸鱼小李”联名共建。

## 为什么火
仓库创建 7 天即获 1472 Star（2026-07-08），热度契合两个趋势：
- **公众号创作者追求效率**：传统编辑器（135、秀米）操作繁琐，且样式粘贴后常错乱，本项目用脚本确定性兜底，免去反复调试。
- **AI Agent 工作流兴起**：项目专为 Agent 设计，输入输出全是纯文本，模型无关，能从“写完文章”直接延伸到“一键排版”，提升内容发布闭环的自动化程度。

## 技术栈
- **核心语言**：HTML（内联样式），辅以 Python 3 校验脚本
- **Agent 集成**：通过 `SKILL.md` 定义工作流，任何支持 skills 绑定（npx skills add）的 Agent 均可执行
- **组件体系**：每种主题由设计变量表 + 数十个组件块 + 视觉层级表 + 配方表构成，存为 Markdown，Agent 按规则装配
- **验证工程**：双关卡脚本 `component_lint.py`（源头）和 `validate_gzh_html.py`（产物），确保零 ERROR 才交付

## 核心能力
- **智能排版**：自动章节编号、关键词下划线标记、全角标点转换、作者签名去重、引言卡与目录提取
- **主题生成器**：用自然语言描述或参考图，由 AI 生成全新组件库并登记复用，打破主题数量限制
- **公众号平台适配**：禁用 `<style>/<div>/class/position` 等特性，所有文字 `<span leaf="">` 包裹，图片、GIF、代码块等均按平台规范处理
- **质量保障**：源头组件库反模式检查 + 产物合规扫描，实现“改→验→修”闭环保真
- **Agent 友好**：无平台锁定，Claude Code、Codex、Cursor 及国产模型都能跑出一致效果

## 適用场景
- 技术教程、操作指南（代码块多、步骤多）
- 深度观点、分析长文（红白、石墨极简主题）
- 测评/工具盘点（摸鱼绿/票据风）
- 数据报告、案例复盘（橄榄手记）
- 生活随笔、禅意文字（留白禅意）
- 任何需要将 Markdown/Word/PDF 转公众号排版的场合

## 同类对比
- **传统编辑器**（135、秀米）：手工拖拽，样式花哨但粘贴易丢失，无版本管理，难以批量处理和自动化。
- **其他 Markdown 转 HTML 工具**（md2html 等）：面向 Web，不处理公众号 CSS 限制，粘贴后常崩坏。
- **本项目**：唯一专为公众号限制设计的 AI Agent 排版技能，组件库可复用，质量由脚本保证，天然融入 AI 工作流，且主题可无限扩展。
