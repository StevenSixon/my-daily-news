## 它是什么

一个面向个人散户的A股量化工作台，提供**选股、回测、信号监控、个股分析、连板梯队、AI复盘**等全套功能。基于TickFlow数据源（可选免费历史数据），后端FastAPI+Polars/DuckDB进行高性能计算，前端React提供仪表盘。所有能力均自托管，Docker单容器零运维，LICENSE MIT完全开源。

## 为什么火

- **开箱即用的完整工作流**：覆盖“发现策略→回测验证→监控盘中信号→AI辅助复盘”闭环，无需拼接多个工具。
- **AI深度整合**：LLM可生成选股策略、分析个股技术/基本面/财务/消息面，并自动写每日复盘，降低量化门槛。
- **社区与成本优势**：依托TickFlow生态免费档历史日K，项目Star快速过千（发布仅两周），社区（LINUX DO）推动，个人开发者无需付费即可上手。

## 技术栈

- **前端**：React 18 + Vite + TypeScript + Tailwind + Tanstack Query + Lightweight Charts/ECharts
- **后端**：FastAPI + Pydantic v2 + APScheduler + sse-starlette
- **数据**：Polars 高性能计算引擎 + DuckDB 查询 + Parquet 列存
- **回测**：vectorbt（唯一的pandas边界），支持T+1/手续费/滑点/止损
- **AI**：OpenAI 兼容接口（DeepSeek/通义/Ollama等）
- **部署**：Docker 两阶段构建，前后端合一容器

## 核心能力

- **选股引擎**：18个内置因子策略 + 自定义Polars信号 + AI生成策略，毫秒级扫描全A股
- **指标流水线**：MA/EMA/MACD/RSI/KDJ/布林等落地enriched Parquet，供后续复用
- **回测引擎**：因子回测（IC/IR/分层收益）与策略回测（净值曲线/夏普/回撤/交易明细），SSE流式进度
- **监控中心**：策略/个股信号/价格/异动四类规则，支持多条件AND/OR，飞书实时推送
- **个股分析**：9类关键价位叠加AI四维分析（技术/基本面/财务/消息面），财务三大表AI解读
- **连板梯队**：连板层级统计、概念/行业分布、炸板预警，可切换连跌梯队
- **复盘**：盘后AI自动生成市场复盘，可定时推送、下载Markdown
- **数据扩展**：支持接入第三方接口/CSV/JSON，与内置数据同台分析

## 适用场景

- 散户个人量化研究，无需购买商业平台
- 策略快速回测与优化，尤其是结合AI生成思路
- 盘中实时监控异动和自定义信号
- 盘后AI辅助复盘，系统化学习市场情绪

## 同类对比

- vs vnpy：vnpy偏向实盘交易接口，本项目聚焦研究端，提供AI辅助和全界面交互
- vs backtrader/qlib：缺乏内置UI和LLM集成，需大量编码
- vs 通达信/同花顺：闭源，无法自定义策略回测，无AI驱动
- 独特优势：自托管保证数据隐私，Polars引擎速度远超Pandas，AI降低策略开发门槛，且项目活跃更新快
