## 它是什么
OmniRoute 是一个开源免费 AI 网关（MIT 协议），通过单一 OpenAI 兼容端点（/v1）聚合 237 个 AI 供应商（含 90+ 免费层），并内置自动故障转移和 Token 压缩引擎。它能无缝对接 Claude Code、Cursor、Cline 等主流编码工具，让用户用上免费的 Claude/GPT/Gemini 等模型。

## 为什么火
截至分析时 Star 数超 13k，社区活跃。核心吸引力在于：
- **零成本起步**：聚合 90+ 免费供应商，每月稳定提供约 16 亿 free token，首月可达 21 亿；
- **免配额焦虑**：多层自动回退（订阅→API→廉价→免费），消除限流中断；
- **Token 节省**：RTK + Caveman 堆叠压缩技术可减少 15–95% 的 token（工具输出多的场景平均省 89%）；
- **一站式集成**：一个配置让所有 IDE/CLI 连接所有模型，大幅降低切换成本。

## 技术栈
- **语言**：TypeScript
- **核心机制**：RTK/Caveman 文本压缩、17 种路由策略（auto/* 组合）、智能故障转移
- **协议支持**：OpenAI API 翻译、MCP（95 个工具）、A2A(Agent-to-Agent)、多模态 API
- **部署形态**：Docker 镜像 / npm 包 / 桌面应用 (Electron) / PWA
- **质量保障**：21,000+ 测试用例

## 核心能力
- **一端点聚合**：openai、anthropic、gemini 协议互译，统一 `/v1` 接口
- **自动回退**：订阅额度耗尽自动切到免费或廉价供应商，无感知
- **Token 优化**：对 `git diff`、`grep` 等工具输出进行高比例压缩
- **桌面/PWA 应用**：提供可视化仪表盘管理提供商和使用量
- **免费额度仪表板**：实时显示各供应商的文档化免费 token 额度及当月使用情况
- **MCP/A2A**：内置工具协议，可直接作为 Agent 后端
- **生产级特性**：断路保护、TLS 伪装、多种代理设置

## 适用场景
- 个人开发者想免费使用高级大模型编码，不希望充多份 API 订阅；
- 团队需要稳定的 AI 编码助手基础设施，避免单一供应商故障；
- 重度 agent 用户（大量工具调用）需要降低 token 消耗成本；
- 网络受限地区通过内置代理访问 AI。

## 同类对比
与 LiteLLM 等开源网关相比，OmniRoute 在聚合大量免费供应商和 Token 压缩方面具有独特性，并原生支持桌面应用和丰富的 IDE 集成配置。但 README 未提供详细的性能基准、延迟对比或兼容性矩阵，无法量化其网关效率优势。
