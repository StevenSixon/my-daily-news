## 它是什么
OmniRoute 是一个自托管的 AI 网关，将 237 个模型提供商（其中 90+ 提供免费层）聚合为一个统一的 OpenAI 兼容端点（`/v1`）。项目用 TypeScript 编写，可运行在本地、服务器、桌面（Electron）或 PWA 中。它的核心卖点是「免费」——通过智能路由和回退机制，优先使用免费提供商的额度，并在额度耗尽时自动降级到备选方案，实现“永不因限流而中断”。内置 RTK + Caveman 压缩可降低 15-95% 的 token 消耗，特别适合工具调用密集型场景；同时支持 MCP（95+ 工具）、A2A 等代理协议，能与 Claude Code、Cursor、Cline 等 24+ 编码代理无缝集成。

## 为什么火
- **切中成本痛点**：AI 工具订阅费高昂，免费 API 分散且有限，OmniRoute 自动聚合并最大化利用免费额度，实测每月可提供约 16 亿免费 token。
- **开箱即用**：无需注册多个平台，一个命令启动本地网关，所有支持 OpenAI API 的工具可直接接入。
- **工程实用性**：17 种路由策略、4 层自动回退、Circuit Breaker、TLS 指纹伪装，甚至考虑到了多账号并发时的配额获取节流，生产级可靠性。
- **社区爆发**：仅创建 5 个月内 Star 近 12k，社区活跃，多语言文档齐全。

## 技术栈
- 语言：TypeScript（Node.js 后端 + Electron 桌面）
- 部署：npm 包（`omniroute`）、Docker、Electron 桌面应用（下载量可见）、PWA
- 协议适配：提供 OpenAI 兼容 API，内部转换向各家提供商（Claude、Gemini、OpenAI 等）的协议，支持 MCP、A2A
- 压缩自研：RTK + Caveman 双层压缩算法
- 生态集成：24+ 编码工具配置示例（Claude Code、Codex、Cursor 等）

## 核心能力
**1. 聚合免费资源**：整合 90+ 免费提供商，去重后动态展示可用额度（文档称每月 ~16 亿 token，首月含注册奖励可达 21 亿），用户无需管理多把钥匙。
**2. 智能路由与回退**：支持 17 种路由策略（成本、延迟、可靠性等），可配置「Combo」组合；自动回退链：订阅 API → 廉价 API → 免费提供商，保证服务不中断。
**3. Token 压缩**：堆叠的 RTK + Caveman 压缩技术，在工具输出（git diff、grep 等）场景平均节省 89% token，显著降低用量和成本。
**4. 工具/代理原生支持**：内置 MCP 服务器（95+ 工具）、A2A 协议，可作为 AI 代理的“大脑”中枢。
**5. 企业级特性**：Circuit Breaker、配额获取节流、per-request 控制头（模式/预算）、审计日志等。**0 配置即可启动**：默认使用内置免费提供商，无需任何 API 密钥。

## 适用场景
- 个人开发者希望免费使用多种大模型（Claude、GPT、Gemini 等）进行日常编码、写作或实验。
- 使用 Claude Code、Cursor 等编码工具的用户想降低 API 花费且不被限流打断。
- 需要高可用 LLM 接入的小团队或项目，利用自动回退和多提供商冗余。
- 对 token 用量敏感的工作流（如长对话、代码库分析），利用压缩大幅节省开销。

## 同类对比
同类项目如 LiteLLM、OpenRouter、One API 等也提供统一 API 端点，但 OmniRoute 的差异化在于：
- **强免费导向**：专为最大化免费额度设计，内置数十个免费提供商，开箱即用，而 LiteLLM 等更偏向企业统一管理付费 API。
- **Token 压缩**：独特的两层压缩技术，直接降低请求成本，同类项目未见此功能。
- **全面工具适配**：除了网关功能，还内置 MCP 工具、A2A 协议、多代理编码工具集成指南，更接近“AI 代理基础设施”。
- **本地优先/隐私**：完全自托管，数据不经过第三方，适合敏感环境。
