## 它是什么
Open Code Review（OCR）是阿里巴巴内部经过百万级缺陷验证的AI代码审查CLI工具，采用**确定性工程+LLM Agent混合架构**，能生成行级精度的审查意见，支持OpenAI/Anthropic等兼容模型，免费开源。

## 为什么火
- **生产验证**：在阿里内部服务数万开发者，识别数百万缺陷。
- **Benchmark背书**：基于50个仓库、200个PR、1505个真实问题评测，对比Claude Code，**精确度更高，Token消耗仅1/9**，F1显著领先。
- **确定性工程**：文件选择、分组合并、规则匹配、位置修正等均用工程保证，不走样、不遗漏、不漂移。

## 技术栈
- Go语言开发，通过npm分发预编译CLI（工具类型，用户无需Go环境）
- 支持OpenAI、Anthropic等多模型后端，LLM作为Agent驱动动态审查
- 内置微调规则集：空指针、线程安全、XSS、SQL注入等
- 集成Git diff解析、代码搜索、仓库级别上下文

## 核心能力
- **智能文件过滤与合并**：打包关联文件，分治处理超大变更集，支持并发审查
- **场景调优Prompt与工具集**：生产数据驱动，比通用Agent更稳定、精准
- **外部定位与反射模块**：独立修正位置与内容准确性
- **全文件扫描模式**：无需diff即可审查整个代码库
- **多环境支持**：CLI、VSCode插件、Claude/Codex/Cursor集成、CI/CD（GitHub/GitLab/Bitbucket等）

## 适用场景
- 对误报率敏感的团队（需要高精度Review）
- 需要CI流水线集成自动Review
- 大型代码库变更，通用Agent容易遗漏或胡言乱语
- 安全/质量规则强制检查（内置规则+可自定义）

## 同类对比
- **Claude Code等通用Agent**：覆盖不全、位置漂移、质量波动大；OCR以工程约束显著提升精度，Token成本仅1/9，但召回率略低（故意牺牲）。
- **传统静态分析（SonarQube等）**：规则固定，缺乏上下文语义理解；OCR用LLM补充语义。
- 其他AI Review工具（未提供直接对比数据，但从Benchmark看其对通用Agent的优势明显）
