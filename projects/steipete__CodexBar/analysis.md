## 它是什么
CodexBar 是一个仅驻留 macOS 菜单栏的微型应用，聚合了 OpenAI Codex、Claude Code、Cursor、Gemini、GitHub Copilot 等 57 个 AI 编程及相关服务的用量限制与计费指标。它直接从本地 CLI 凭证、浏览器 Cookie、OAuth token 或 API Key 读取数据，实时展示额度、窗口截止倒计时、成本图表，并提供状态预警与合并图标模式。

## 为什么火
- **聚合刚需**：开发者同时使用多个 AI 编码工具，频繁切换网页或 CLI 查看配额效率极低。一个统一的菜单监控极大减少中断。
- **隐私设计**：数据完全在本地解析，无需发送到任何服务器，仅复用已有的本地认证文件，不要求额外密码。
- **覆盖面广**：57 个提供商涵盖主流及小众服务，从 OpenAI 管理 API 到国产 Kimi、DeepSeek、豆包等，甚至包括 AWS BedRock 成本分析。
- **开发者友好**：提供 CLI 工具 `codexbar` 用于脚本化和 CI 成本统计，Linux 下也可通过 CLI 使用。
- **活跃迭代**：自 2025 年底创建以来快速积累 16k+ Star，v0.40.0 已展现极高的更新频率和社区贡献。

## 技术栈
- 原生 Swift 编写，目标平台 macOS 14+。
- 菜单栏使用 AppKit 实现，WidgetKit 支持小组件。
- 本地数据源包括：Chromium/WebKit/Safari 的 Cookie 及本地存储（需 Full Disk Access），Keychain 中的 OAuth 令牌，CLI 配置文件（如 Claude Desktop 日志、Augment CLI、Gemini CLI 等），环境变量或 API Keys。
- 没有后台服务，所有解析在进程内完成；配置存储于 `~/.config/codexbar/config.json`，文件权限严格限制。
- 跨平台 CLI 构建：Swift 静态链接，Linux 下提供 glibc 和 musl 版本。

## 核心能力
- **多提供商用量仪表盘**：每个提供商独立的菜单条项目（可合并为一个图标加切换器），显示用量条、百分比、剩余额度。
- **重置倒计时**：精准到秒的会话/每周/每月窗口结束时间，帮助任务规划。
- **成本扫描**：对 Codex、Claude 等支持本地日志的提供商，解析历史 token 消耗并生成成本费趋势图；OpenAI Admin API 等可直接拉取账单数据。
- **提供商状态轮询**：服务中断时（如 OpenAI 宕机）在菜单栏图标上覆盖警示标记。
- **灵活认证方式**：OAuth、设备流、浏览器 cookie、API Key、本地文件、CLI 凭证等自动协商。
- **CLI 工具**：`codexbar cost --provider codex` 等命令可输出成本报告，供 CI/脚本使用。
- **小组件 & 通知**：WidgetKit 小组件展示关键提供商的用量，配额即将耗尽时可推送通知。
- **国际化与无障碍**：21 种语言界面，支持动态文本和画外音。

## 适用场景
- **个人开发者**：日常监控 Claude Code、Cursor、Copilot 等多工具额度，避免在忙碌编码时突然中断。
- **自由职业者/小团队**：统计月度 AI 编码支出，辅助报销或成本控制。
- **学生/试用用户**：了解免费额度剩余，合理规划编码任务。
- **CI/CD 环境**：利用 CLI 输出成本数据，集成到自动化监控或告警中。
- **多账户用户**：通过 Claude 多账户卡、Claude-swap 等支持，同时监控工作和个人账户。

## 同类对比
目前没有直接竞争产品（多 AI 编码平台本地聚合监控）。被动需登录各网站查看或使用 CLI 命令如 `claude status` 是普遍现状。CodexBar 填补了视觉化、集中化监控的空白，且本地解析 + 零信任模式优于任何云端同步方案。
