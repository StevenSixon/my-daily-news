## 它是什么
CubeSandbox 是一个基于 RustVMM + KVM 的微虚拟机沙箱服务，为 AI Agent 提供即时、安全、轻量的代码执行环境。每个沙箱拥有独立 Guest OS 内核，通过硬件级隔离运行不可信代码，启动时间低于 60ms，内存开销小于 5MB，且完全兼容 E2B SDK，可无缝迁移现有 Agent 工作流。

## 为什么火
AI Agent 需要频繁执行 LLM 生成的代码，传统方案面临安全与性能的两难：Docker 共享内核有逃逸风险，传统虚拟机启动慢、密度低。CubeSandbox 在两者间找到**完美平衡**——毫秒级冷启动使 Agent 执行不卡顿，硬件级隔离满足生产安全需求，单节点可运行数千个沙箱，显著降低运营成本。项目开源仅数周即获 7k+ Star，并进入 CNCF Landscape，侧面印证了市场对这类方案的高度渴望。

## 技术栈
- 核心：Rust 编写，底层使用 RustVMM + KVM 实现微虚拟机管理
- 文件系统：自研 CubeCoW 写时复制快照引擎，支持百毫秒级快照、克隆、回滚
- 网络与安全：eBPF 增强隔离，内置加密流量令牌、出口控制与凭证保险柜
- 模板系统：基于 OCI 镜像，支持一键创建和分发沙箱模板
- 部署：单机或集群，提供 Terraform 部署器，新增 ARM64 原生支持
- 兼容层：原生 E2B SDK 兼容，Web 控制台管理，Python/JS 客户端

## 核心能力
- **极致性能**：冷启动 <60ms（单并发），50 并发下平均 67ms，P99 137ms；内存开销 <5MB，密度极高
- **硬件隔离**：每沙箱独立内核 + eBPF 加固，杜绝共享内核逃逸
- **E2B 兼容**：改动环境变量即可迁移现有代码，支持文件系统、PTY 等完整 API
- **生命周期自动化**：v0.5 新增 AutoPause/AutoResume，自动休眠闲置沙箱并按需唤醒，释放物理资源
- **快照与版本控制**：运行时可快照、克隆、回滚，适合强化学习、Agent 分支执行等场景
- **安全增强**：凭证保险柜（秘钥不入沙箱）、出口流量围栏、每沙箱独立访问令牌

## 适用场景
- 为 AI Agent 提供安全的 Python/Shell 代码执行环境（如 OpenAI、LangChain、AutoGPT 等集成）
- 强化学习训练中的环境快照与回滚（如 SWE-Bench 测评）
- 多租户 SaaS 平台中安全隔离客户代码
- 浏览器自动化、自动化测试等高隔离需求任务
- 需要高密度、低成本的 Serverless 运行时

## 同类对比
- **Docker 容器**：共享内核，隔离性弱，但启动较快（约 200ms）
- **传统 VM（QEMU/KVM）**：强隔离，但启动需数秒，内存开销大，单机密度低
- **Firecracker**：AWS Lambda 的开源微 VM，启动通常在 125ms 左右，无 E2B SDK 兼容及完整 Agent 工具链，CubeSandbox 在启动速度和生态集成上更具优势
- **其他 AI 沙箱（如 E2B 自身）**：E2B 为商业产品，CubeSandbox 提供开源替代且性能对标，加上自托管、无供应商锁定等特性，更受自建平台青睐
