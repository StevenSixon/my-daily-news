## 它是什么
Klaat Code 是一个终端原生 AI 编程代理（CLI），安装后可在任何项目中使用。它读取代码、编辑文件、运行命令并验证工作。其核心依赖 Klaatu 路由服务，该服务根据请求复杂度将任务分派到不同成本层级的模型（nano→heavy），自动升级或降级，以降低令牌成本。

## 为什么火
- **成本大幅降低**：对比 Claude Code、Cursor 等，在保持同等解决率（33/33）的同时，单任务成本仅 $0.027，是 Claude Code 的 1/5.4。
- **智能模型路由**：自动按需分配模型，无需手动切换。
- **无额外工具回合收费**：只有用户消息计费，工具调用、重试免费，避免“继续”按钮中断。
- **可复现基准**：提供基准测试脚本，用户可自行验证性能数据。

## 技术栈
- 语言：TypeScript
- 运行环境：Node.js ≥18 或 Bun ≥1（编译为二进制后无需运行时）
- 路由服务：Klaatu（服务端托管，非本地运行）
- 支持模型：Claude、GPT、Gemini、DeepSeek 等，也支持自带 OpenAI 兼容端点
- 安装方式：npm、Homebrew、curl 一键脚本、Windows PowerShell

## 核心能力
- **智能模型路由**：五层路由（nano/fast/code/reason/heavy），自动调整。
- **代码知识图谱**：项目索引为调用图，支持语义搜索和爆炸半径分析，减少令牌消耗。
- **编辑后诊断**：自动运行类型检查/静态分析，错误直接反馈模型修正。
- **终端 UI**：语法高亮、片段折叠、鼠标支持、主题切换、Vim 键绑定。
- **实际计划模式**：只读模式规划，批准后切换到完整工具执行。
- **内置工具**：文件读写编辑、补丁应用、全局搜索、命令执行、网页抓取/搜索、任务列表、子代理委托等。
- **成本可见与控制**：实时消耗速率监控、任务成本归属、令牌预算、硬上限。
- **上下文管理**：压缩前快照、验证摘要、透明告知模型丢失内容。

## 适用场景
- **日常编码辅助**：重构、调试、生成样板代码。
- **CI/CD 集成**：无头模式执行“修复所有 TS 错误”等任务，支持 `--max-cost` 预算。
- **成本敏感型用户**：希望用 AI 深度辅助但不愿支付前沿模型全额费用。
- **喜欢终端工作流**：不依赖 IDE，纯命令行交互。

## 同类对比
- **Claude Code**：相同解决率，但平均成本高 5.4 倍。
- **Cursor**：成本比 Klaat Code 高 1.7~3.5 倍，且速度慢（Composer 2.5 标准 113s vs Klaat Code 23s）。
- **opencode**：成本相近，但速度慢 5 倍左右，且解决率略低（31/33）。
- **Aider/Grok Build**：未提供直接对比数据，但基准提及 Grok Build 前序测试成本约 $0.058。
