## 它是什么
eve（Vercel出品）是一个文件系统即配置的AI代理框架。通过在 `agent/` 目录下放置 `instructions.md`（系统提示）、`tools/`（类型安全函数）、`skills/`（按需加载流程）、`channels/`（消息渠道）和 `schedules/`（定时任务），即可定义代理的全部行为。框架解析目录结构并运行为持久化代理，支持本地开发和 Vercel 部署。

## 为什么火
Star 超 3000，诞生仅半月，得益于 Vercel 品牌效应和“文件系统优先”的极简理念。它降低了从零搭建 TypeScript 代理的门槛，且文档内置于 npm 包，AI 编码助手可直接读取。

## 技术栈
- 语言：TypeScript
- 运行时：Node.js
- 类型校验：Zod
- 模型接入：通过配置（如 `anthropic/claude-sonnet-5`），支持多模型
- 集成：Slack、Discord、HTTP 频道，Twilio 语音原语
- 部署：Vercel（推测为默认目标），也可本地运行
- 快照与沙盒：开发运行时生成快照以恢复代理状态，支持沙盒执行

## 核心能力
1. **声明式配置**：文件结构即代理逻辑，无需大量代码。
2. **类型安全工具**：`defineTool` 配合 Zod schema，模型调用结果强类型。
3. **子代理与技能**：支持代理委派子任务，技能可按需加载。
4. **失败恢复**：v0.19.0 修复了子代理失败时传播错误结果，工具失败返回失败内容，代理可在同一轮次内重试。
5. **多频道输出**：内置 Slack、Discord、HTTP 等，也可自定义。
6. **开发体验**：`npx eve init` 脚手架，`npm run dev` 启动交互终端；开发快照优化，减少磁盘占用。

## 适用场景
- 需要工具调用的智能客服
- 自动化工作流与定时任务
- 多步骤推理的助手（如旅行规划）
- TypeScript 全栈应用的 AI 功能集成
- Vercel 平台的 AI 代理快速部署

## 同类对比
- **vs LangChain**：eve 更轻量，用文件约定代替链式代码，学习曲线平缓，但生态较新。
- **vs AutoGPT / CrewAI**：eve 更注重生产可靠性和可控性，而非自主迭代。
- **vs Mastra（TypeScript 代理框架）**：eve 强调文件系统驱动，配置与代码分离，更适合团队协作。
- **vs OpenAI SDK**：eve 提供完整的代理运行时和工具编排，不只是 API 封装。
