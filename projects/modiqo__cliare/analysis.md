## 它是什么

CLIARE（CLI Agent Readiness Evaluation）是一个黑盒式的 CLI 测量工具，像对待 AI 代理一样去执行被测命令行程序，记录运行时行为、推断命令表面、检测副作用，并生成命令索引、记分卡、问题清单和多种角色的报告。它的理念是将 CLI 的命令表面和运行时行为客观化，为 CLI 的维护者、安全审核者和下游的 AI 代理框架提供可版本化的契约。

## 为什么火

随着 AI 代理越来越多地以终端作为操作界面，传统面向人类的 CLI 在命令发现、输出解析、前置条件和副作用方面对代理极不友好。CLIARE 填补了这一空缺：它不依赖手写文档，而是通过实际运行 CLI 来测量“代理就绪度”，将模糊的反馈转化为可量化的修复项和可用于代理路由的命令索引。这对于希望保持 CLI 生态对 AI 代理友好的开源项目和平台非常关键。

## 技术栈

- **语言**: Rust
- **安装方式**: `cargo install cliare` 或预编译二进制（支持 macOS/Linux x86_64 与 aarch64）
- **输出格式**: JSON、Markdown、JUnit XML、SARIF 等
- **核心依赖**: 自主实现的进程启动、文件系统快照、上下文探测等（未列出具体库）

## 核心能力

- **黑盒探测与证据记录**：支持干净环境、仓库环境、认证环境、宿主机环境等多种运行时上下文，记录 stdout/stderr、文件系统变更等证据。
- **命令表面推断**：通过执行 `--help`、试探性参数等，推断出命令路径、标志、位置参数和输出格式，生成 `shape.json` 和 `command-index.json`。
- **代理就绪评分与问题清单**：生成总分与细项分数（帮助覆盖率、诊断信息、可解析输出、不安全行为等），并提供每个发现的含义、关联命令、证据摘录和修复建议。
- **角色化报告**：内置 `maintainer`（维护者实现队列）、`harness`（代理框架集成包）、`security`（安全审计包）三种透视。
- **代理技能与命令索引分离**：明确区分“教代理如何判断”的技能和“命令实际支持什么”的索引，前者由CLIARE生成 `AGENT_SKILL.md`，后者由 `command-index.json` 提供可查询的路由支持。

## 适用场景

1.  **CLI 维护者**：在 CI 中把 CLIs 的代理就绪度作为发布关卡，提前发现帮助文档缺失、无声的副作用、输出契约不足等问题。
2.  **代理框架构建者**：利用命令索引和路由查询命令（`surface query`, `surface explain`）避免代理反复猜测命令语法，降低 token 浪费和故障率。
3.  **安全审计团队**：检测看似“安全”的命令（如 `--help`, `--version`, `--invalid-flag`）是否偷偷写入了文件，或者需要非预期的认证/网络权限。

## 同类对比

- **传统 CLI 测试工具（如 bats, assert_cmd）**：侧重功能正确性，不关注命令表面的完整性和代理就绪性，不产生可供下游消费的规范化索引。
- **OpenAPI/Swagger 文档**：用于 HTTP API，而 CLIARE 是第一个**从运行时证据自动生成 CLI 命令表面描述**的工具，类似“CLI 的 Swagger”。
- **手工编写代理技能**：多数代理框架依赖手工编写工具使用说明，CLIARE 将这部分工作自动化，并使得技能说明与真实 CLI 行为保持一致。
