## 它是什么
Cindy 是一个开源的 AI Agent 客户端（Apache-2.0），提供桌面（Electron）和移动端（React Native）应用。它能在本地机器上运行，直接使用你的文件和登录态，通过接入多个“harness”（如 Claude Code、Codex）和模型，完成从代码编写、文件操作到浏览器/设备控制的实际任务。用户可登录官方云服务、使用自己的 API 密钥，或选择本地模式（无需登录，但服务器功能缺失）。

## 为什么火
- **复用已有订阅**：直接调用你已付费的 Claude Code / Codex 计划，无需重复付费。
- **本地优先 + 开源**：隐私受控，可审计、修改和扩展。
- **跨设备编排**：能在桌面和手机间协同工作，驱动浏览器、文件系统和应用。
- **开箱即用**：无需自行托管后端，官方云服务现成可用，也支持本地模式。

## 技术栈
- 语言：TypeScript
- 框架：Electron（桌面），Expo / React Native（移动）
- 工程：pnpm monorepo，Git LFS
- 开发依赖：Node.js 22.x, pnpm 10.x
- 后端：客户端通过端点配置连接官方云服务（cn/global），源码仓库仅含客户端及协议子模块（cindy-protocol）

## 核心能力
- **多 harness/模型混合**：Claude Code、Codex 等，支持任务中动态切换，模型记忆与技能跨 harness 共享。
- **任务规划与并行**：允许一个任务在不同 harness×模型组合上规划、并行执行并由其它代理评审。
- **设备控制**：操控浏览器、电脑和手机，从 IM 或日程获取工作指令。
- **记忆与技能**：修正一次后永久生效；可定义可重用工作流（技能共享仍在开发）。
- **MCP 集成**：连接内部工具和业务系统。
- **插件系统**（规划中）：可改变功能、界面和交互，通过开放市场分享。

## 适用场景
- 开发者自动化：代码审查、重构、文档生成、环境配置。
- 多设备任务：在电脑上启动构建，手机查看通知并执行后续操作。
- 本地数据敏感的工作：需要操作本地文件但担心隐私泄露的场景。
- 团队协作（待技能共享成熟）：批量处理重复性工作流。

## 同类对比
- 与 **AutoGPT / AgentGPT** 相比：Cindy 不只是 web 代理，而是原生客户端，直接控制本地应用和手机；开源协议更宽松。
- 与 **Claude 桌面应用 / ChatGPT 桌面** 相比：Cindy 聚合多家模型和 harness，并允许复用已有订阅，不绑定单一模型提供商。
- 与 **LangChain / CrewAI** 框架相比：Cindy 是面向最终用户的产品级客户端，开箱即用，而非需自行组装的开发框架。
