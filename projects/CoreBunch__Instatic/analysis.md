## 它是什么
Instatic 是一个 MIT 开源的视觉化站点构建器（CMS），旨在成为 Webflow、Framer 和 WordPress 的开源替代。它把画布编辑器、内容引擎、发布器全部集成在一个 Bun 服务器中，输出纯语义 HTML 和紧凑 CSS，页面干净到可以直接 view-source。数据存储支持 SQLite 和 Postgres。

## 为什么火
项目创建于 2026 年 4 月底，仅三个月已获 5000+ Star。极客群体看重的点：绝对的自主托管、无供应商锁定；视觉编辑不污染代码输出；内置完整的 Core Framework 设计令牌系统（色彩、排版、间距自动生成）；更难得的是拥有一个可以真正编辑页面结构的 AI 代理。这些特性精准击中了厌倦 SaaS 锁定的开发者。

## 技术栈
- 运行时：Bun（TypeScript everywhere）
- 数据：SQLite 或 PostgreSQL
- 容器化：单 Docker 镜像，支持 Railway、Render、VPS 等一键部署
- 插件沙箱：QuickJS-WASM 隔离执行，无文件系统/环境变量/网络访问（按需授权）
- 设计引擎：Core Framework（从设计令牌生成 utility CSS 类）

## 核心能力
- **视觉设计**：多断点并排编辑、Core Framework 设计令牌（自动生成色阶、流体排版、间距比例）、统一 utility CSS 输出。
- **构建模块**：拖拽式模块（容器、文本、图片、表单等），可复用视觉组件（带类型参数和插槽），模板与循环输出，表单直接存入自有数据表。
- **AI 代理**：Site scope（35 工具）可构建页面，Content scope（15 工具）编辑内容；支持 Claude、OpenAI、OpenRouter、Ollama，用户自带 key 和模型。
- **内容与数据管理**：统一的数据模型（`data_tables`/`data_rows`），自定义集合和工作流，媒体文件管理器，基于能力的角色权限（TOTP、账户锁定），命令面板 ⌘K。
- **分析**：可拖拽小部件仪表盘、不可篡改的审计日志、自有表单数据无第三方依赖。
- **扩展**：插件系统通过沙箱安全运行后端代码，前端扩展需明确权限，支持路由、存储、定时任务等。

## 适用场景
- 个人博客、作品集、小型企业官网
- 需要视觉搭建但坚持代码洁癖的前端开发者
- 想脱离 Webflow/WordPress 托管且保留设计灵活性的团队
- 希望用 AI 快速生成页面但保持最终 HTML 静态、可控的项目

## 同类对比
|   | Instatic | Webflow | Framer | WordPress |
|--|----------|---------|--------|-----------|
| 开源/自托管 | ✅ MIT 自托管 | ❌ SaaS | ❌ SaaS | ✅ 开源但生态复杂 |
| 静态输出纯净度 | 高（无框架残留） | 中等（w-* 类等） | 低（大量 JS） | 依赖主题 |
| 内置设计系统 | ✅ Core Framework | CSS 类 | 对标设计工具 | 需插件 |
| AI 代理建站 | ✅ 原生集成 | 第三方 | 无 | 需插件 |
| 插件隔离 | QuickJS-WASM 沙箱 | 无 | 有限 | 无强制沙箱 |
