## 它是什么
OpenChatCut 是一个开源的本地理视频编辑器，融合了专业多轨时间线与 AI 代理能力。它不生成“一次性视频”，而是把代理的编辑动作（剪切、转场、字幕、特效）直接写入可撤销的工程中，保留完整的手动编辑控制。项目面向需要自动化剪辑但又不想放弃精细调整的创作者和开发者，并提供外部 MCP 集成，让 Codex、Claude Code 等工具直接操作视频工程。

## 为什么火
传统视频编辑软件依赖手动操作，而 AI 视频生成工具产出难以微调的最终文件。OpenChatCut 在二者之间架起桥梁，解决“自动化与可控不可兼得”的痛点。其本地优先设计保证数据和媒体留在本地，同时 Agent 原生架构使编辑过程变成对话驱动。2026 年 7 月发布即获 530+ Star，活跃开发状态和完整的桌面/Web 支持吸引了早期用户。

## 技术栈
- 语言：TypeScript
- 前端：React 19
- 桌面壳：Electron 43
- 视频渲染与导出：Remotion 4 + FFmpeg（硬件加速自动检测）
- Agent 集成：MCP（Model Context Protocol），支持外部 Streamable HTTP 客户端
- 视觉效果：WebGL/GLSL 滤镜、动画
- 构建：npm + Node.js 24

## 核心能力
- **多轨时间线**：视频、音频、转场、特效、关键帧、标记、撤销/重做
- **AI 代理**：内置会话代理，支持技能调用、提案式编辑；外部 MCP 代理共享相同工具
- **转录驱动编辑**：词级转录，基于文本的剪切、停顿处理、说话人识别、自动字幕
- **生成类媒体**：图像、视频、语音、音乐、音效生成，进度跟踪
- **动态图形与 WebGL**：可编辑模板、自定义着色器、视觉效果库
- **发布级导出**：MP4、音频、字幕、FCPXML、工程数据导入导出
- **本地优先**：工程与媒体默认存本地，API 密钥服务端保持

## 适用场景
- **访谈/口播剪辑**：转录后通过文本快速删除错误、停顿，自动生成字幕
- **多格式快速组装**：导入素材后让代理生成粗剪、转场和配乐
- **短视频/社交内容**：改变画布、一键生成标题、解说、音乐
- **动态图形制作**：使用内置模板或让代理生成可编辑 MG 片段
- **开发者自动化**：通过 MCP 让外部编码代理检查/修改项目

## 同类对比
与传统时间线编辑器相比：多了自然语言控制与代理参与，可检查、可撤销。
与一次性 AI 视频生成工具相比：保持精确的轨道和剪辑控制，结果可继续编辑。
与 ChatCut 商业产品相比：完全开源（AGPL），本地运行，但不提供官方云服务。
