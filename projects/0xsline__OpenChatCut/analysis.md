## 它是什么

OpenChatCut 是商业软件 ChatCut 的开源替代品，一个将**对话式AI代理**与**专业多轨时间线**融合的视频编辑器。项目数据全部本地存储，支持通过内置代理或外部 MCP 客户端（如 Claude Code、Codex）对项目进行读取、编辑和导出，且所有改动都写入真实轨道、剪辑、转场和字幕，始终可手动调整与撤销。

## 为什么火

- **打破生成与编辑的壁垒**：传统时间线编辑器精确但无自然语言接口，一键生成工具输出不可改；OpenChatCut 让代理产出的结果始终是**可编辑的项目**，而非一次性渲染。
- **开放生态**：基于 MCP（Model Context Protocol），允许第三方代理工具共享同一套编辑能力，便于深度学习开发者将视频编辑纳入自动化流水线。
- **本地优先 & BYOK**：默认不依赖云服务，API 密钥留在服务端，敏感的媒体素材和项目结构保存在用户机器上。
- **开源与早期势头**：AGPL-3.0 协议，仅半年已有 559 Star，提供桌面安装包与源代码，活跃开发中。

## 技术栈

- **语言/框架**：TypeScript、React 19、Remotion 4（用于程序化视频渲染）
- **桌面壳**：Electron 43
- **渲染与媒体**：FFmpeg（自动选择硬件加速）、WebGL（视觉效果与自定义着色器）
- **AI 集成**：内置对话代理（支持提案式编辑）与 MCP 外部代理接口；支持图像/视频/语音/音乐/音效生成任务；转录、文字驱动剪辑
- **工程化**：本地优先架构、Node.js 24.x、环境变量配置模型与媒体服务

## 核心能力

| 领域 | 已实现功能 |
|------|------------|
| 时间线 | 多轨剪辑、移动、修剪、分割、波纹编辑、吸附、关键帧、标记、无限撤销/重做 |
| 视觉 | WebGL 效果（像素化、双色调、鱼眼、万花筒、漏光等）、LUT、色度键、缩放、转场 |
| 音频 | 多轨、音效库、背景音乐、录音、响度标准化、自动闪避、人声隔离 |
| 转录与字幕 | 词级转录、暂停压缩、说话人标记、自动字幕（多种预设样式）、翻译、时间线叠加、SRT 导出 |
| 运动图形 | 内置可编辑模板、安全沙箱、自定义模板、视频渲染 |
| AI 生成 | 图片、视频、语音、音乐和音效生成作业，带进度追踪 |
| 代理 | 内置对话式代理、技能系统、提案式编辑；外部 Streamable HTTP MCP 支持 |
| 导出 | MP4、音频、字幕、FCPXML、项目导入/导出、导出历史、硬件加速 H.264、资源感知队列 |
| 媒体管理 | 上传、文件夹、在线媒体搜索（图片/视频/音频）、Firecrawl 视觉媒体回退 |

## 适用场景

- **谈话类节目/采访剪辑**：转录 -> 文字级删除错误/停顿 -> 自动生成字幕
- **多格式快速粗剪**：导入视频/图片/音频，代理自动生成粗剪、转场、配乐和节奏
- **短视频与社交内容**：画布重构、自动标题、字幕、配音、音乐包装
- **运动图形自动化**：使用内置模板或让代理创建可编辑的 MG 片段
- **开发者自动化**：通过 MCP 接入 Claude Code / Codex 等客户端，编程式检查和修改视频项目

| 转录与视觉联动 | 部分 | ❌ | ✅ |

与商业 ChatCut 相比，OpenChatCut 提供完全开源、自我托管的替代方案，且强调代理可编辑的真实项目，而非黑盒生成。
