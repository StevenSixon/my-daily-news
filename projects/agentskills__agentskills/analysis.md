## 它是什么
Agent Skills 是一套轻量、开放的文件格式标准，用于给 AI Agent 添加领域知识和可重复工作流。每个技能是一个文件夹，核心文件是 `SKILL.md`，包含元数据和指令，还可附带脚本、模板、参考资料等。它由 Anthropic 发起，已有多款 Agent 产品采用。

## 为什么火
当前 AI Agent 虽强，但常常缺乏特定领域的上下文和标准化操作流程，导致结果不可靠。Agent Skills 通过打包“公司/团队/个人特有的过程性知识”为可版本控制的文件夹，让 Agent 按需加载，既不占用常态上下文，又能随时调用专业能力。跨客户端的格式统一性让技能一次构建、到处使用，大大降低了定制 Agent 的摩擦。

## 技术栈
- 规格本身以 Markdown + YAML 形式定义，辅以 Apache 2.0 许可的参考实现代码（仓库中 `client-implementation` 目录）。
- 配套文档站点（agentskills.io）基于 MDX 构建。
- 技能包内可包含任意语言编写的脚本（常见 Python），但格式本身与语言无关。

## 核心能力
1. **标准化结构**：技能通过 `name`、`description` 等元数据声明自身能力，Agent 启动时只加载这些摘要，实现“发现”阶段。
2. **渐进式加载**：匹配任务后激活完整指令，执行时可调用捆绑的脚本或资源，确保上下文只有在真的需要时才膨胀。
3. **跨产品复用**：符合该格式的技能可在所有支持 Agent Skills 的客户端中使用，目前已有多个产品展示（见官网 Client Showcase）。
4. **生态开放**：规范开放贡献，社区可参与改进。

## 适用场景
- 企业内部自动化：将代码审查流程、数据处理流水线、合规检查等固化为技能，让 AI 同事一致执行。
- 垂直行业 Agent：法律文件审查、医学文献检索、财务分析等场景，封装专业知识和工具。
- 个人助理定制：重复性任务（如整理笔记、生成特定格式报告）存档为技能，随调随用。
- 跨团队共享：一个团队沉淀的最佳实践，其他团队直接复用，无需重新训练或提示工程。

## 同类对比
- **OpenAI Plugins / GPT Actions**：绑定特定平台，无法跨客户端复用；Agent Skills 是客户端无关的简单文件格式。
- **LangChain Tools / Semantic Kernel Skills**：这些是框架层面的工具抽象，虽然可以表达能力，但定义方式依赖代码和特定运行环境；Agent Skills 更像一个发布格式，可以兼容各种框架的实现。
- **Prompt libraries**：只提供静态提示词，缺乏可执行脚本和资源模板的捆绑能力。

核心竞争力在于**极简、不绑定平台、全客户端可共享**。
