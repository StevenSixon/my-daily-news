## 它是什么
Waku 是一个本地优先的个人 AI 助手，代码量极简（一个下午可读完）。项目通过四大支柱展示 Agent 的本质：**网关 (Harness)** 管理多通道接入，**循环 (Loop)** 在约 95 行 Python 中实现推理-工具调用-观察，**记忆 (Memory)** 用单个 SQLite 文件存储语义、情节和程序记忆，**评估/运维 (Eval/LLM-Ops)** 内置确定性测试与 LLM 裁判。

## 为什么火
作者 Sean 在其 YouTube 系列《Sean's AI Stories》中从架构白板到代码完整公开构建过程，让开发者看透每个模块。项目口号是“在代码中看懂 Agent”，无黑盒框架，所有核心逻辑简洁透明，配合可视化仪表盘直观展示内部状态。

## 技术栈
- Python，使用 `uv` 管理依赖
- 记忆：SQLite + FTS5，分为语义、情节、程序记忆，自动生成 `MEMORY.md` 镜像
- LLM 适配：支持 Anthropic/OpenAI/Gemini/DeepSeek/MiniMax/Kimi/GLM/xAI/OpenRouter，统一循环，~60 行适配层
- 前端：纯静态本地仪表盘，无构建步骤
- 集成：CLI、语音唤醒词、Telegram、Discord
- 评估：确定性测试 + LLM-as-judge，带发布门
- 实验：子代理委托（调用 pi 编码代理）

## 核心能力
- **多通道统一**：CLI、Web 仪表盘（127.0.0.1:7777）、语音、Telegram、Discord 共用同一大脑
- **记忆自决**：检索门判断“是否需要回忆”，整合器决定“保留什么”；支持 Notion 写回
- **Agent Loop**：推理→工具调用→观察→继续，支持多步复杂工具链（如搜索后批量创建日历事件）
- **实时仪表盘**：观测每轮迭代的门决策、工具调用、token 消耗与成本
- **评估管道**：内置评估矩阵与回归测试，可量化模型表现
- **Arena 模式**：同一提示对比多模型，记录完成度、裁判评分、延迟、真实成本
- **数据透明**：提供只读 SQLite 浏览器，查看 `state.db` 全部表

## 适用场景
- 想深入学习 Agent 架构与实现的开发者（尤其是记忆与工具调用）
- 需要全本地、隐私敏感的个人日程/知识助手
- 教学、演示及团队内部技术分享（配套可编辑架构图）
- 快速原型验证 Agent 设计模式

## 同类对比
- 对比 ChatGPT/Claude Desktop：Waku 是代码库，完全可审计、可修改，而非封闭产品
- 对比 OpenClaw/Hermes 等大型开源助手：架构相同但代码量极低（约 1/100），是“可读蓝图”而非全功能产品
- 对比 LangGraph 等框架：没有抽象层，直接展现循环本质，降低学习曲线
