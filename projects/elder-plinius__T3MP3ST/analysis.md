## 它是什么
T3MP3ST 是一个自主红队平台，用多智能体（8 角色）编排攻击链，从侦察、漏洞利用到报告全自动。直接对接你本机已登录的 AI 编码代理（Claude Code、Codex、Hermes），无需额外 API 密钥或云服务，实现“零密钥战争”。

## 为什么火
- **零成本启动**：借用现有 AI 代理，不增加账单。
- **可验证声明**：所有基准测试分数可通过 `npm run verify-claims` 从提交的 artifacts 重新计算，拒绝虚假数字。
- **黑盒成绩**：在 XBOW 的 104 项挑战集上黑盒 pass@1 达 90.1%，超越 XBOW 自报的 85%。
- **真实 CVE 验证**：在 2026 年公开 10 个真实 CVE 上（后训练截止日期），单个代理准确定位到文件、行和 CWE 的 8/10，全集发现 10/10，排除了背诵和过拟合。
- **透明地标记状态**：明确区分稳定、实验性和计划中的功能。

## 技术栈
- **语言**：TypeScript
- **架构**：多智能体框架，包含侦察、武器库、任务引擎、MCP 服务器、HTTP API
- **默认工具**：35 个内置工具，可选 `T3MP3ST_FULL_ARSENAL` 扩展到 83 个（含渗透/后利用工具，需人工审批）
- **验证**：基于提交的 JSON oracle 进行声明验证

## 核心能力
- **侦察**：工具驱动的实时 nmap/DNS/HTTP/指纹扫描，输出可追溯。
- **利用**：基准验证的漏洞利用循环，单代理在 XBEN 上 90.1% pass@1。
- **代码审计**：支持 Python 源码白盒分析（实验性），在 CVE-Zero 中成功定位多语言漏洞。
- **协同披露管道**：OSV 新颖性检测 + 实时 PoC + 反驳者面板 + CVSS 生成，但仅产出草稿，由人工发送。
- **领域覆盖**：Web、CTF、网络、嵌入式/机器人/OT、源码、智能合约（部分实验性）。

## 适用场景
- 授权渗透测试和红队演练
- 安全研究者快速验证漏洞
- CTF 挑战无提示求解
- 开源供应链漏洞挖掘（协同披露）
- 安全培训中的自动攻击模拟

## 同类对比
- vs 传统红队工具（Metasploit 等）：T3MP3ST 利用 AI 代理进行智能决策，减少人工干预。
- vs 其他 AI 红队项目：强调可重现性、零密钥和透明状态表；直接在 XBOW 基准上得分更高（90.1% vs 85%）。
- 不足：完整 8 代理蜂群的实际端到端利用效率尚未基准测试，目前主要成果来自单代理。
