## 它是什么
T3MP3ST 是一个开源的多智能体攻击安全元框架，把你已经登录的 AI 编码代理（Claude Code、Codex、Hermes 或本地模型）变成自主漏洞猎手。它把杀伤链自动化：侦察 → 利用 → 报告，全程通过浏览器 War Room 或 CLI 操作，不依赖额外的 API 密钥或云账单。

## 为什么火
- **可重现的基准**：在 XBOW 的 104 项挑战套件上达到 pass@1 均值 90.1%（Wilson 95% 置信区间 86.2–92.9），高于 XBOW 自报的 85%，所有数字可通过 `npm run verify-claims` 从提交的 JSON 数据重新推导，杜绝虚假宣传。
- **无密钥架构**：直接复用本机已有的 AI 编码代理作为决策大脑，无需注册任何云服务，甚至支持 Ollama/LM Studio 完全离线运行。
- **透明状态**：明确标注各个模块的成熟度（稳定/实验/规划），不自夸未经验证的功能。
- **多域覆盖**：Web 应用、CTF、智能合约、源代码审计、嵌入式/OT 等领域均有不同程度的支持，且新领域采用可组合的“类/小队”架构。
- **安全约束**：内置出口范围遏制，防止侦察工具访问无关公网主机。

## 技术栈
- 核心语言：TypeScript
- 架构：8 操作员的杀伤链（Recon/Exploit/Infiltrate/Exfiltrate/Ghost 等），每个操作员共享同一个基于真实工具的 ReAct 循环
- 工具库：默认 35 个内置工具，可选扩展至 83 个（通过 `T3MP3ST_FULL_ARSENAL` 开启危险组件，需人工审批）
- 接口：War Room Web UI、CLI、HTTP API、MCP 服务器
- 支持模型：可通过本机 AI 代理（Claude Code/Codex/Hermes）或 OpenAI 兼容 API（包括 Ollama、LM Studio、vLLM）驱动，工具调用通过文本实现，不强制要求原生函数调用
- 测试与验证：所有声称指标均可通过 `npm run verify-claims` 从 `bench/` 中的 JSON 重新计算

## 核心能力
- **侦察引擎（稳定）**：实时驱动 nmap、DNS、HTTP 指纹等工具，每个发现可追溯至原始输出。
- **漏洞利用（实验性）**：下游操作员运行与侦察相同的工具驱动循环，但 swarm 协同下的端到端利用尚未基准化，单代理模式有 90.1% 的 XBEN 成绩。
- **协调披露管道**：针对嵌入式/OT 开源软件的漏洞探测，包含 OSV 新漏洞检查、实时 PoC 生成、独立重复验证和 CVSS 评分（目前停留在草稿，由人工发送）。
- **源码分析（实验性）**：Python 正则引擎摄取，支持多模型分解（实际 token 成本更高）。
- **CTF 解决**：Cybench 无提示模式下解决 23/40 挑战。
- **零密钥集成**：直接劫持本地已登录的 AI 编码代理，实现“无密钥战争”。
- **自验证机制**：运行一条命令即可重算所有 headline，保证数据不掺假。

## 适用场景
- 授权渗透测试与红队演练
- 安全研究中的自动化漏洞发现与验证
- CTF 训练与解题辅助
- 开源供应链及物联网固件的协调披露
- 安全教学，展示 AI 驱动的攻击路径

## 同类对比
- **传统红队框架（Metasploit、Cobalt Strike）**：T3MP3ST 由 AI 代理自主规划攻击链，无需手动编写利用模块，但其 swarm 协同利用的稳定性远不及成熟商业工具。
- **AI 安全基准项目（如 XBOW）**：T3MP3ST 不仅开源、支持离线，还将控制权交给本机已有的编程代理，并公开完整的验证方法，透明性更高。
- **其他 LLM 安全工具**：多为提示词插件或静态扫描，缺少完整的工具链和行动循环。
