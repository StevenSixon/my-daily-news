## 它是什么
T3MP3ST 是一个**多智能体进攻性安全元框架**，用 TypeScript 打造，AGPL-3.0 许可。它把用户已有的 AI 编程代理（Claude Code、Codex、Hermes）或本地模型武装为自主红队，执行“侦察→利用→报告”完整杀伤链。通过浏览器 War Room 或 CLI 操作，**无需额外 API 密钥、无需云账户**，完全自托管。

## 为什么火
- **免信任的基准**：在 XBOW 的 104 题黑箱基准上取得 **90.1% pass@1**（高于 XBOW 自报的 85%），且所有数字可通过 `npm run verify-claims` 从提交数据重新推导，零信任话语。
- **零密钥、全离线**：后台驱动是本地已装的 AI 代理，或基于 Ollama/LM Studio 的本地模型，彻底消除外部 API 依赖。
- **极致透明**：现状态表明确标注稳定/实验/计划功能，Swarm 等高级能力虽然引擎真实但仍不可靠，不吹嘘。
- **社区热度**：创建仅 3 天即获 2232 Star，迅速吸引安全与 AI 社区眼球。

## 技术栈
- **语言**：TypeScript（运行时 Node.js）
- **多智能体架构**：8 操作员杀伤链（Op Admiral 指挥，Recon、Exploiter、Infiltrator、Exfiltrator、Ghost 等），每个运行真实工具驱动的 ReAct 循环。
- **后端支持**：Claude Code、Codex、Hermes 等编码代理；API 密钥模式（OpenRouter、Anthropic、OpenAI、xAI Grok）；**完全离线**模式（Ollama、LM Studio、vLLM 等 OpenAI 兼容服务）。
- **工具箱**：默认 35 个工具（nmap、DNS、HTTP 等），可切换到完整兵工厂 83 个工具（含 Metasploit、Hydra 等需人工审批的后渗透工具）。
- **集成接口**：MCP 服务器、HTTP API，War Room Web UI。

## 核心能力
- **侦察引擎（稳定）**：真实驱动 nmap/DNS/HTTP 指纹，所有发现可溯源至工具输出。
- **协调披露管道（稳定）**：OSV 新颖性检测 + 实时 PoC + 反驳面板 + CVSS，自动生成草稿，人工发送。
- **基线验证**：run `verify-claims` 即可从原始数据重算所有基准数字，确保可复现性。
- **出口范围封锁（稳定默认开启）**：锁定目标后，内置网络工具禁止访问目标范围外的公共主机，防止越界扫描。
- **白盒代码分析（实验）**：目前仅支持 Python 正则提取，多模型分解成本较高。
- **Swarm 协同（实验）**：各操作员均可独立使用工具循环，但端到端的 8 智能体协作仍未基准化，实际不够可靠。

## 适用场景
- 授权渗透测试人员快速自动化侦察与常见漏洞利用
- CTF 选手练习或参加无提示挑战（Cybench 23/40）
- 嵌入式/机器人/工控等开源软件的漏洞挖掘与协调披露
- 企业内网自测，利用本地代理避免数据外泄
- 安全研究人员探索多智能体攻防框架

## 同类对比
- **vs XBOW**：在相同基准上自称超越 XBOW 5 个百分点，且强调可复现；相对 XBOW 闭源商业平台，T3MP3ST 完全开源、本地可跑。
- **vs 传统红队工具**（如 Metasploit、Cobalt Strike）：自动化程度更高，借助 AI 代理自主决策，但仍依赖成熟利用脚本。
- **vs 其他 AI 安全代理**：独特之处在于**零密钥**、**离线**、**强化可复现性验证**，以及不带节奏的状态标注。
