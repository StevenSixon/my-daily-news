## 它是什么
Hermex 是专为开源 AI 代理服务器 [hermes-webui](https://github.com/nesquena/hermes-webui) 设计的原生 iOS 客户端应用。它让 iPhone 成为私有代理的控制平面，而不是计算平面——所有模型、工具和数据都留在你的硬件上，手机仅通过密码保护的 HTTP 连接发送指令和接收流式响应。

## 为什么火
- **隐私至上**：零分析、零追踪、零第三方中转，直接对话自托管服务器。
- **原生体验**：纯 SwiftUI 构建，支持 iOS 18+，响应迅速，非网页套壳。
- **功能完整**：聊天（流式、多模型、文件附件）、任务与技能管理、工作区文件浏览、记忆与洞察只读面板。
- **完全免费**：无订阅、无内购，MIT 开源。

## 技术栈
- 语言：Swift 5.9+
- UI 框架：SwiftUI
- 最低系统：iOS 18+
- 依赖管理：Swift Package Manager
- 后端对接：通过 HTTP 与 hermes-webui 通信，容忍式 JSON 解码（未知字段不崩溃）

## 核心能力
- **代理聊天**：发送消息时可选择模型、推理力度、工作区及配置文件，支持图片与文件附件，实时流式展示思考过程和工具调用细节。
- **会话管理**：离线缓存已浏览的对话，支持搜索和恢复。
- **多模型切换**：从服务器可用模型中选择，支持最近使用和收藏。
- **任务与技能**：查看和编辑代理的 cron 定时作业；搜索已安装的代理技能。
- **工作区浏览**：通过应用内文件浏览器查看服务器文件系统。
- **只读面板**：代理记忆与使用分析（Insights）一览。

## 适用场景
任何已部署自托管 hermes-webui 并希望通过手机随时控制 AI 代理的技术用户，尤其是对隐私敏感、不希望数据经过云服务的高级用户。

## 同类对比
与通用的云 AI 客户端（如 ChatGPT 官方应用）相比，Hermex 不信任任何外部服务；与网页版控制台相比，它提供了更快的启动、更好的移动触摸交互和平台集成。它唯一的“竞品”是开发者自行搭建的快捷指令或自定义网页，但 Hermex 在体验上更完整且原生。
