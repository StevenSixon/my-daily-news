## 它是什么

Superpowers 是一个软件工程方法论与可组合技能框架，专为 AI 编码代理（Claude Code、Cursor、Gemini CLI 等）设计。它不依赖特定平台，通过插件机制注入初始指令和一套自动触发的技能，将代理的行为从“看到需求就写代码”重塑为完整的 SDLC：头脑风暴 → 设计文档 → 实现计划 → 子代理驱动开发（SDD）→ TDD → 代码审查 → 分支完成。

## 为什么火

该项目让编码代理的自主开发变得可预测且高质：代理会主动细化需求、写出精确到文件路径的任务、使用隔离分支和双阶段审查（spec 合规 + 代码质量），并具备修复循环与断路器。对需要“发呆几小时但不出错”的开发者极具吸引力。Star 超过 26 万，社区活跃，由经验丰富的开发者（Jesse Vincent）维护。

## 技术栈

仓库主要为 Shell 和 Markdown 文件。核心是技能定义（SKILL.md）和初始引导指令，不同平台的插件实现各异的 hook 注入，并不包含重型服务端组件。本质上是以提示工程为中心的轻量级框架。

## 核心能力

- **自动化的需求精炼**：brainstorming 技能通过苏格拉底式提问产出设计文档。
- **精细的任务规划**：将工作拆解为 2–5 分钟可完成的原子任务，每个任务明确文件路径、代码和验证步骤。
- **子代理驱动开发 (SDD)**：每个任务分派独立的子代理，执行后经过 spec 合规与代码质量两阶段审查，不合格则返回修复，最多五轮，超限后由控制者裁决。
- **严格的 TDD**：强制红-绿-重构循环，删除任何未经过测试的代码。
- **全生命周期覆盖**：从创建 git worktree、自动执行计划、代码审查，到收尾分支的合并/PR/丢弃决策。
- **跨平台即插即用**：支持 Claude Code、Cursor、Codex、Gemini CLI、Copilot CLI 等十余种代理，安装仅需一行指令或插件市场操作。

## 适用场景

- 使用 AI 编码代理加速日常开发的个人或团队
- 希望代理自主完成中等复杂功能、保持代码质量一致性的场景
- 需要代理在后台长时间工作（数小时）而不偏离设计的项目
- 无法或不愿托管代码到外部 AI 开发平台的企业

## 同类对比

与 Devin、Sweep 等全托管 AI 开发助手相比，Superpowers 更轻量、可运行在本地代理上，用户完全控制代码和流程；与 Aider 的“architect 模式”相比，它的流程更加固化和系统化（强制设计-计划-审查-修复循环），但灵活性稍弱。其跨代理能力是突出优势。

## 版本动态

最新 v6.2.0 引入了重要的 SDD 结构变更：工作区按计划作用域隔离，避免跨任务污染；修复循环改为恢复原实施者而非重新派发；添加五轮断路器和控制者裁决。整体技能文档进行大幅压缩，去除说服性文案，保留关键逻辑，并通过子代理探针验证行为。项目仍在积极迭代。
