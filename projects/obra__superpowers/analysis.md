## 它是什么
Superpowers 是一套给 AI 编码代理（如 Claude Code、Cursor、Copilot CLI）用的软件开发方法论和可组合技能库。它不只是一个提示词模板，而是通过自动触发的技能文件，强制代理在写代码前先做设计、制定分步任务、采用 TDD，并用子代理独立实施每个任务，事后进行代码审查。

## 为什么火
该项目解决了 AI 编码工具普遍存在的“直接输出代码、缺乏规划和测试”的问题。在 2025 年发布后迅速获得 24.5 万星，因为其工作流与专业软件工程实践高度契合，且支持市面上几乎所有主流编码代理，形成了事实标准。

## 技术栈
- 技能本身以 Markdown 文件（SKILL.md）定义，通过各代理的插件机制加载
- 核心可能涉及少量 Shell 脚本（如安装、打包），主要逻辑为自然语言指令
- 未披露特定的编程语言，代理将技能内容作为指令吸收

## 核心能力
- **强制工作流**：代理启动时自动激活，按 brainstorming → 规划 → 子代理 TDD → 审查 → 完成分支的固定流水线执行
- **子代理驱动开发**：每项任务交付一个新代理（干净上下文），用“先规格后质量”的双阶段审查
- **多代理适配**：支持 Claude Code、Cursor、Codex、GitHub Copilot CLI 等 10 余种工具，安装方式各不相同但技能通用
- **元技能**：包含 writing-skills 让用户扩展自己的技能，遵循相同规范

## 适用场景
- 希望用 AI 编码但要求代码经过严格 TDD 和评审的团队
- 在已有 Git 项目中使用，自动创建 worktree 进行隔离开发
- 快速尝试不同解决方案（通过并行子代理）
- 需要统一多个编码代理行为的工具链

## 同类对比
与单功能的编程助手插件（如只生成代码或只做代码审查）不同，Superpowers 提供的是一整套方法论，强制代理遵循从设计到合并的完整流程。与 GitHub Copilot Workspace 等方案相比，它更轻量、与具体代理解耦，且完全由社区驱动（MIT 许可）。
