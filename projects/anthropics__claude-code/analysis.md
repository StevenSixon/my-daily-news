## 它是什么
Claude Code 是 Anthropic 推出的 agentic 编码工具，直接运行在终端。它能通过自然语言命令理解整个代码库，并执行例行任务、解释复杂代码、处理 Git 工作流。你可以在终端、IDE 或 GitHub 上使用它。

## 为什么火
仓库 Star 数超过 13.5 万，创建仅一年多。它把 AI 助手直接嵌入开发者的日常工作环境（终端），无需切换上下文即可完成代码修改、提交等操作，大幅降低使用摩擦。来自 Claude 模型的强大能力背书，社区关注度极高。

## 技术栈
- 语言：Python（仓库主要语言），安装方式支持 curl/bash 脚本、Homebrew、WinGet 等
- 接口：终端 CLI 工具、VS Code/JetBrains 插件、GitHub @claude 集成
- 运行依赖：Node.js 18+（npm 安装版，但已标记废弃）
- 数据交互：读取代码库，通过对话生成命令和修改

## 核心能力
- 理解整个代码库上下文
- 执行日常编码任务（如自动写代码、修改、重构）
- 用自然语言解释复杂代码段
- 处理 Git 工作流（commit、branch 等）
- 支持插件系统，可扩展自定义命令和智能体
- 后台 agent 会话，支持异步运行和恢复
- 多平台安装（macOS/Linux/Windows）

## 适用场景
- 快速理解大型陌生代码库
- 自动化重复性编码任务（样板代码、批量重构）
- 终端内完成日常 Git 操作（提交、分支管理）
- 在 IDE 中作为 AI 助手补充
- 适合偏好命令行操作、追求效率的开发者

## 同类对比
与 GitHub Copilot、Cursor、Codeium 等工具相比，Claude Code 更强调终端原生体验和完整的自然语言驱动操作，可直接给出 shell 命令并执行修改。它不是简单的代码补全，而是一个可以自主执行多步骤任务的智能代理。优势在于与 Claude 模型深度整合，且对代码库级别的理解较强。
