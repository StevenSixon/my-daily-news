## 它是什么
Palmier Pro 是一个开源的 macOS 视频编辑器，完全用 Swift 构建，将专业剪辑能力与 AI 深度整合。编辑器本身免费、开源，内置生成式 AI 功能（需订阅），并通过 MCP 服务器暴露接口，允许 Claude Code、Codex、Cursor 等 AI 代理直接操作时间线、管理项目，实现人与 AI 在同一项目上协同创作。

## 为什么火
- **YC S24 项目**，发布后 Star 数快速突破 1.2 万，在 X 和 Discord 社区引发关注。
- 精准踩中 AI 代理 + 创作的赛道，将传统视频编辑器的能力通过 MCP 暴露给任意 AI 工具，打开了无代码/低代码剪辑的新方式。
- 编辑器本身免费、无登录即可使用，直接对标 CapCut/ Premiere，降低了开发者和创作者尝试的成本。
- 仅支持 macOS 26 (Tahoe) Apple Silicon，体现了对苹果最新技术的激进采纳，吸引早期探索者。

## 技术栈
- **语言**: Swift
- **平台**: macOS 26 (Tahoe) on Apple Silicon
- **AI 集成**: 内置生成式模型（Seedance, Kling, Nano Banana Pro），生成处理部分闭源
- **协议**: MCP (Model Context Protocol) 服务器，基于 HTTP，默认端口 19789
- **许可**: GPL-3.0（编辑器及 MCP 部分开源），生成 AI 功能闭源

## 核心能力
- **专业剪辑功能**: 多轨道时间线、文字动画、裁剪、过渡效果、预览速度控制、独立文字缩放旋转、边缘圆角/柔化等。
- **AI 代理操控**: 通过 MCP 服务器，支持 Claude Code/Desktop、Codex、Cursor 直接控制时间线，实现自动剪辑、添加文字、调整音量等操作。
- **内置生成式 AI**: 在时间线内直接使用 Seedance、Kling 等模型生成视频和图像。
- **项目搜索与批量删除**: 近期版本加入，提升多项目管理效率。
- **跨语言支持**: 提供 15 种语言的 README，面向全球开发者。

## 适用场景
- 开发者想通过 Claude 或 Cursor 编写脚本自动化视频编辑流程。
- 创作者利用 AI 代理快速生成字幕、添加特效或调整节奏。
- 需要集成 SOTA 生成模型进行内容填充的视频项目。
- 希望拥有类似 Premiere 能力但要求更轻量、可编程剪开的 macOS 用户。

## 同类对比
- **vs. Adobe Premiere/Final Cut Pro**: Palmier Pro 免费、开源，且通过 MCP 提供了外部 AI 操控能力，Premiere 的 AI 功能以插件形式存在，无法如此深度地让外部代理控制整个编辑环境。
- **vs. CapCut**: CapCut 专注于消费级视频剪辑，AI 功能内敛；Palmier Pro 开放了 MCP 和开源代码，更适合技术用户。
- **vs. DaVinci Resolve**: Resolve 在调色和专业后期上更强大，但其脚本 API 不是为 AI 代理设计的，Palmier Pro 的 MCP 集成更现代、更统一。
