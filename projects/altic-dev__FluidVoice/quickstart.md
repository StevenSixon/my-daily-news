## 安装
```bash
brew install --cask fluidvoice
```
或从 [Releases](https://github.com/altic-dev/FluidVoice/releases/latest) 下载 `.dmg`。

## 前置条件
- macOS 15.0+，推荐 Apple Silicon（Intel 仅支持 Whisper 模型）。
- 需授予麦克风和辅助功能权限。

## 快速体验
1. 启动 FluidVoice，完成初始设置，选择语言和语音模型（可先选 Apple Speech 零门槛）。
2. 在设置中绑定一个全局快捷键（如 `⌃⌥Space`）。
3. 打开任意文本输入区域，按下快捷键开始说话，实时看到文字。
4. （可选）在设置中开启 Fluid Intelligence，下载约 3.5 GB 本地 AI 模型，即可获得格式化增强。
