## 它是什么
Pi Web 是 [pi 编码代理](https://github.com/badlogic/pi-mono) 的本地 Web UI，用 TypeScript 编写。它直接读取本地的 pi 会话文件，在浏览器中提供会话浏览、实时聊天、模型/技能管理以及项目文件预览。它不是远程服务，完全运行在用户机器上，通过 Next.js 提供界面。

## 为什么火
Star 2743，源于 pi 用户对更友好交互的需求。命令行下查看 Markdown、工具调用结果、历史会话较吃力，Pi Web 将这些可视化，并支持分叉会话实验、图形化配置模型，完全本地运行，响应快，无需外部依赖。对经常使用 pi 的开发者是效率倍增器。

## 技术栈
- 前端：基于 React + Next.js（推断），SSE 实时推送代理状态
- 后端：Node.js 服务 (≥22.19.0)，内置本地 API，代理会话通过文件系统和 IPC 通信
- 渲染增强：Markdown (Mermaid 图表, KaTeX 数学公式), 文件预览 (源码、图片、音频、PDF、DOCX)
- 安全：默认监听 127.0.0.1，无应用层认证，仅用于可信网络

## 核心能力
- **会话浏览与分支**：按项目展示历史对话，可从任意消息继续或 Fork 新分支
- **实时协作**：通过 Web UI 发指令，实时查看 pi 的工具调用、思考过程和格式化输出
- **文件资源管理**：左侧文件树，右侧多格式预览，可与对话并行浏览
- **模型与技能配置**：图形界面管理模型列表、API 密钥、默认模型，测试模型连接，启用/禁用技能
- **Git 工作树集成**：侧边栏切换 Git worktree，会话和文件浏览器自动跟随检出
- **安全加固**：本地 API 限制跨域、规范化工作区路径、约束文件上传与附件范围

## 适用场景
- 经常回顾、复用 pi 历史会话的开发场景
- 需要安全地尝试不同对话思路（Fork）而不污染原会话
- 终端预览不便时（长 Markdown 文档、Mermaid 图表、LaTeX 公式、多媒体文件）
- 快速切换模型或技能而无需编辑配置文件的单机/团队内网环境

## 同类对比
- **通用聊天界面 (Open WebUI / Lobe Chat)**：支持多后端、知识库，但不深度集成 pi 的工具调用结果渲染和项目文件系统，缺乏会话分支管理
- **IDE 插件 (Cline / Continue)**：嵌入编辑器，与开发流程紧耦合；Pi Web 提供独立浏览器环境，适合非 IDE 场景，但同样本地运行
- **原始 CLI**：最基础，Pi Web 是对其的图形化补充，没有引入远程服务或额外复杂性
