## 它是什么
pi-web 是专为 pi coding agent 设计的本地 Web 界面。它读取本地的 pi 会话文件，在浏览器中提供会话浏览、实时对话、模型配置、技能管理和项目文件预览等一系列工作空间功能，使用户无需在终端里翻找历史或手动编辑配置。

## 为什么火
项目在短时间内获得 3000+ star，更新频繁，体现了开发者对终端可视化改进的强烈需求。pi-web 解决了 pi agent 用户在工作流中的几大痛点：难以回溯历史会话、切换 Git 工作树时上下文混乱、配置模型和技能需要手动编辑文件等。它的出现降低了使用门槛，让复杂的 agent 交互变得更可控、更安全。

## 技术栈
- 语言：TypeScript
- 框架：Next.js（基于文件结构中的 app/ 目录、next 构建命令）
- 通信：SSE（Server-Sent Events）用于实时推送 agent 响应
- 运行时：Node.js 22.19.0+
- 安全：本地运行于 127.0.0.1，无应用层认证，支持受限模式和 DNS rebinding 防护
- 格式：基于 JSONL 的会话文件，完全兼容 pi CLI 的数据存储

## 核心能力
- **会话浏览与分支**：按项目分组展示历史会话，支持从任意消息继续（编辑创建分支）或 fork 为独立会话文件
- **文件浏览器与预览**：左侧文件树支持源码、Markdown、图片、音频、PDF、DOCX 等预览，新版本加入快速变更查看和 diff 模式
- **实时聊天**：与后台 agent 通过 SSE 进行消息交互，支持图像拖放发送、思考等级、工具调用结果渲染
- **模型与技能管理**：Web 界面直接读写 models.json，管理 API 密钥、模型测试和默认模型；技能可安装、启用/禁用
- **Git 工作树切换**：从侧边栏切换工作树，新会话和文件浏览器自动跟随选中版本，同一仓库的 worktree 间可保留标签页
- **受限模式与信任界面**：对于不受信项目仅加载受限功能，需完成信任确认后才能激活项目扩展，增强本地安全
- **国际化**：支持英文与简体中文，语言自动检测与菜单切换，方便非英语用户
- **扩展状态栏**：与 pi CLI 对齐的扩展状态指示，固定在底部操作栏

## 适用场景
- pi agent 用户希望用可视化界面替代终端操作，提高效率
- 需要频繁切换分支或回溯历史会话的开发者，避免在命令行中手动拼凑路径
- 团队或个人在本地开发环境中安全使用 agent，不希望将数据暴露至外部服务
- 多语言用户更方便地使用 pi 生态

## 同类对比
与通用的 AI 编程辅助界面（如 Continue、Cursor）不同，pi-web 深度绑定 pi coding agent 的特定会话结构和工具调用范式，能准确呈现结构化 tool call 和 Markdown 结果。它完全自托管在本地，不依赖外部服务，数据隐私无泄漏风险，且提供项目级别的文件预览和工作树切换，这些是通用界面难以提供的。开源 MIT 协议，社区可自由定制。
