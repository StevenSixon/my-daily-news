## 它是什么
Umadev 是一个使用 Rust 编写的编码代理，模拟一个完整的开发团队（产品经理、架构师、UI/UX、前后端工程师、QA、安全、DevOps 及协调者），驱动你已经登录并使用的 AI 编程 CLI（Claude Code、Codex、OpenCode）在一个持续会话中完成从需求到交付的全流程。

## 为什么火
上线不足一个月即获 226 Star，因其独特的定位：将现有的 AI CLI 视为“大脑”和“双手”，自身充当团队级指挥官，提供规划、研究、文档生成、质量门禁和交付证明，并内置离线本地 RAG，解决了直接使用 AI 编码时缺乏结构、前后端脱节、无验收标准等常见痛点。

## 技术栈
- 核心：Rust（单二进制）
- 分发：npm 包装壳，预编译二进制支持 macOS/Linux/Windows
- 检索：双通道混合 RAG（纯 Rust BM25 + 本地向量模型 `multilingual-e5-small`，通过 candle 运行），融合 RRF，支持 HyDE 查询扩展
- 交互：TUI
- 依赖：外部 AI CLI（Claude Code / Codex / OpenCode）作为基座，不持有自有模型

## 核心能力
- **团队模拟**：8个专家角色分别负责需求、架构、设计、前后端、测试、安全、部署，由协调者统筹调度
- **全流程交付**：需求路由 → 澄清 → 研究 → PRD/架构/UI文档 → 执行计划 → 前端 → 预览 → 后端 → 质量门禁 → 交付证明
- **本地知识库**：459 个精选工程标准文件，支持离线向量检索，无需 API 密钥
- **治理与审计**：内置 112+ 条治理规则，每次构建生成合规映射和交付证据包
- **自演化记忆**：从每次运行中学习，改进后续输出（具体机制不详）
- **安全隔离**：在独立的 `umadev/<slug>` 分支工作，不污染当前分支

## 适用场景
- 希望用一句话从零生成完整、可交付的 Web 应用（含规划文档与质量报告）
- 现有团队成员用 AI CLI 编程，但需要引入统一的工程标准、设计约束和上下文持续会话
- 对数据隐私敏感、要求完全离线本地检索的企业环境
- 需要向客户或领导提供可审计交付物的外包或产品团队

## 同类对比
README 未提供直接竞品对比。与全能型自主代理（如 Devin）不同，Umadev 不直接生成代码，而是协调第三方 CLI 执行；与终端辅助工具（如 Aider）相比，它强调团队流程和治理，弱化实时结对编程。由于缺乏量化基准，优势多体现在流程设计和离线能力上。
