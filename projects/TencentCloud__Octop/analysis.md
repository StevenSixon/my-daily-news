## 它是什么
Octop 是一个开源的、完全自托管的 AI 助手平台，面向家庭与小团队。它提供 Web 仪表板、CLI 和多个 IM 频道，通过多智能体架构让每个用户可以切换不同专家角色，同时集成了浏览器自动化、远程桌面和交互式终端等“数字操作”能力。

## 为什么火
- **隐私优先**：所有对话、凭据、工作区都跑在本地，数据不出机器。
- **多用户多专家**：一个管理员账户即可为全家或团队创建独立智能体，并共享专家库。
- **超越对话**：除了聊天，还能操控浏览器、远程桌面、执行命令行，实现自动化任务。
- **插件生态**：Connector 体系支持腾讯系应用、OAuth 和 MCP 网关，扩展能力边界。
- **单进程自托管**：仅需 `octop run` 就运行全部服务，维护成本极低。

## 技术栈
- 语言：Python 3.11+
- Web 框架：FastAPI + uvicorn
- 前端：React 18 + TypeScript + Vite + Ant Design
- Agent 运行时：自研 harness-agent
- IM 网关：harness-gateway
- 数据库：默认 SQLite (WAL)，可选 PostgreSQL
- 容器化：支持 Docker 部署
- 其他：ACP 协议互通、APScheduler 定时任务

## 核心能力
- **多用户隔离**：JWT 认证，管理员可管理用户、分配智能体。
- **专家库**：开机扫描专家库，提供 16 种 MBTI 人格模板与自定义系统提示。
- **工作区后端**：本地磁盘、Docker 容器、PostgreSQL、云存储（COS/S3）均可作为智能体运行环境。
- **记忆可移植**：基于 harness-memory 的全文本搜索，记忆随工作区迁移。
- **IM 集成**：飞书、钉钉、QQ、Discord、企业微信等。
- **自动化**：自然语言或斜杠命令触发定时任务。
- **浏览器/桌面/终端**：内置无头 Chromium 会话、远程桌面、交互式 Shell。
- **ACP 双向支持**：可从 IDE 调用 Octop 智能体，也可让 Octop 委派外部编码工具（如 Claude Code、Codex）。

## 适用场景
- 家庭共享 AI 管家：多成员独立会话，专家库覆盖生活、教育、娱乐等。
- 小型团队协作：多人共用连接器，定时抓取信息，自动处理文档。
- 个人极客：自托管聊天 + 远程桌面/浏览器操控，搭建私人 RPA 工作站。

## 同类对比
- 相较于 Open WebUI：Octop 不只是界面，更强调多 Agent 内生、桌面/浏览器操作和 IM 频道，是一个终端到终端的平台。
- 相较于 Dify/Flowise：Octop 更偏向“助手”而非可视化工作流构建，适合需要开箱即用多用户环境的用户。
- 相较于自建 GPT 代理：Octop 把数据库、工作区、记忆、通知、定时任务一体化，降低运维难度。
