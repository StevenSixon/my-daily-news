## 它是什么
Octop 是一款开源自托管的 AI 助手平台，由腾讯云团队开发。它并非简单的聊天机器人，而是一个多用户、多智能体的协作环境，每个用户可拥有多个具备不同人格和专业技能的 AI 代理，并通过 Web Dashboard、CLI、飞书、钉钉、QQ、Discord、企业微信等多种渠道交互。支持 ACP 协议，可与 IDE 相互代理，扩展了编程辅助的场景。

## 为什么火
目前（2026年7月）Star 数仅 414，热度尚低，但项目定位精准：完全本地化部署，隐私性强，避免了云端 AI 服务的依赖，契合技术敏感用户和小型团队的需求。它融合了专家库、MBTI 人格定制、记忆迁移、远程桌面等独特设计，比一般的自托管聊天前端提供了更丰富的智能代理能力，且文档齐全、安装极简，有望在开发者圈中传播。

## 技术栈
- 后端：Python 3.11+， FastAPI + uvicorn， 智能体运行时基于 harness-agent， 网关为 harness-gateway， 控制面使用 SQLite (WAL) + aiosqlite。
- 前端：React 18 + TypeScript + Vite + Ant Design。
- 自动化：APScheduler 实现定时任务。
- 构建与代码质量：hatchling， ruff， mypy， pytest。
- 核心组件：harness-memory（层次化记忆与全文搜索）、harness-browser（CDP 浏览器自动化）。

## 核心能力
- **多用户与多智能体**：每个用户创建多个代理，各自拥有独立工作区、模型供应商和定时任务。
- **专家库与人格**：内置 16 种 MBTI 人格模板及可交互测试，代理可配置不同性格；启动时自动扫描专家库，按场景切换。
- **自托管安全**：JWT 多用户隔离，工具审批、Shell 命令防护、PII 脱敏，所有数据存于本地 `~/.octop/`。
- **可扩展连接器**：支持腾讯文档、微博趋势等 OAuth/MCP 网关，扩展资源边界。
- **可插拔后端**：本地磁盘、Docker 容器、PostgreSQL、COS/S3 等作为 AI 执行边界。
- **记忆迁移**：基于 harness-memory 的层次化记忆，可随工作区迁移。
- **ACP 双向**：`octop acp` 允许外部工具调用 Octop 代理，也可将任务委托给 OpenCode、Claude Code 等外部编码代理。
- **终端与浏览器 AI**：终端 AI 辅助执行命令，浏览器 AI 进行无头自动化、截图等。
- **远程桌面**：通过仪表盘实时控制 Linux/Windows/macOS 桌面，支持无头 Linux 一键隔离桌面。
- **多渠道集成**：支持飞书、钉钉、QQ、Discord、企业微信等即时通讯通道，以及 HTTP/SSE API 编程访问。

## 适用场景
- 家庭或小团队内部共享 AI 助手，每成员有自己的专家代理处理日常事务。
- 开发者需要一个本地 AI 工作台，可调用多种模型、进行安全代码审查、自动化运维。
- 需要私密信息处理的场景（如个人知识管理、敏感对话），所有数据不出本地。
- 通过 IM 通道与企业微信等集成，为团队提供便捷的 AI 入口。
- 远程办公中，用 Octop 代理执行 GUI 操作或自动化任务。

## 同类对比
与 LangChain、AutoGPT 等框架式工具不同，Octop 是完整的自托管产品，而非开发组件。它更类似于 Dify 或 PrivateGPT，但额外提供了多代理人格、远程桌面控制、ACP 双向 IDE 集成和丰富的 IM 桥接。目前版本 v0.9.15，仍处于早期阶段，功能激进迭代中，稳定性待观察。

## 版本动态
最新版本 v0.9.15（2026-07-27）主要进行了稳定化修复：聊天导航避免残留旧会话 URL，优化 Memory/Token Usage 页面布局，并补充企业微信文档。项目仍在密集开发中，Release 频率高，社区参与度有限，未来方向可能持续完善多代理协调和更多连接器。
