## 它是什么
LLM Space 是一个专为 Agent 构建者打造的桌面应用，提供从原型设计、提示词与工具编写、执行追踪、失败回放到性能评估的全流程支持。项目由 DeerFlow 团队孵化，已在内部深度使用（Dogfood），第四个大版本 v4 重构了跨端运行时架构。

## 为什么火
Agent 开发长期依赖在线 Playground 或命令行工具，调试困难、运行不可复现。LLM Space 把 Agent 循环的每个步骤可视化，支持历史运行回放，且所有线程与密钥数据存储在本地，契合极客对数据控制和离线使用的需求。近期新增的 SSH 远程运行时让桌面体验延伸到服务器，进一步扩展了适用场景。

## 技术栈
- 语言与工具链：TypeScript 6.x，使用 Bun 作为运行时与包管理器
- 桌面外壳：Electrobun（轻量原生应用打包方案）
- 前端：React + Tailwind CSS + shadcn/ui
- Agent 框架：内部采用 Pi Agent Core 作为轻量级 Agent 循环引擎
- 项目结构：Bun monorepo，`packages/core` 共享逻辑，`apps/desktop` 桌面壳

## 核心能力
- **构建**：版本化管理提示词、系统消息、工具定义与模型配置
- **追踪**：实时查看模型调用与工具执行的每一步
- **调试**：从历史记录回放运行，逐步排查失败原因
- **评估**：跨多次运行量化 Agent 表现
- **生成**：AI 辅助编写提示和工具，可将任意线程导出为可运行的 LangGraph Agent
- **远程运行时**（v4.6.0）：通过 SSH 连接远程服务器，管理远程线程、文件、工具，状态监控与断线恢复

## 适用场景
- Agent 开发者快速试验新想法而不依赖线上环境
- 调试复杂的多步 Agent 工作流，准确定位失败环节
- 需要本地化管理所有提示和对话记录的团队
- 将桌面交互与远程算力结合（如连接 GPU 服务器跑模型）

## 同类对比
- 对比 LangSmith：LLM Space 更偏本地桌面工具，无需联网即可调试，而 LangSmith 侧重云托管与协作
- 对比 Flowise/Langflow：后两者是可视化管道设计器，LLM Space 聚焦 Agent 循环的检查与回放，更偏向调试向
- 对比本地 CLI 方案：提供 GUI 交互、历史回溯和可视化追踪，降低调试门槛

## 版本动态
- 当前版本 v4.6.0（2026-07-27）
