## 它是什么
Taste Skill 是一套可复用的 Agent Skills（即 SKILL.md 规则文件），专治 AI 编码生成的前端界面千篇一律、缺乏个性。它通过文字指令指导模型在布局、排版、动效和间距上做出更有“品味”的决策，而非提供一个库或框架。

## 为什么火
Vibe Coding 盛行之下，Claude、Codex 等模型输出的 UI 经常出现无趣的通用样式（slop）。Taste Skill 抓住了“让 AI 生成的东西有设计感”这个真实痛点，无需更换技术栈，仅需附加规则即可明显提升输出质量。Star 数增长极快，反映出社区对“防平庸”设计的强烈需求。

## 技术栈
本质是 Markdown 格式的 Agent 技能文件，通过 Vercel 的 `npx skills add` CLI 安装。核心技能用 JavaScript? 其实 README 标了 JavaScript 语言，但实际只是技能描述文本，可能 repo 里有少量配置。

## 核心能力
- **设计调谐三旋钮**：设计方差（VARIANCE）、动效强度（MOTION）、视觉密度（DENSITY），1-10 控制布局激进程度。
- **多技能分工**：默认 taste-skill（v2 实验版）、v1 稳定版、GPT 严格版、图像转代码、项目重设计、极简/野蛮主义等风格技能。
- **图像生成技能**：产出网站/移动端/品牌板参考图，再喂给编码模型。
- **严格语法约束**：硬性禁止 em-dash 等细节，规范 GSAP 动画骨架。

## 适用场景
- 使用 Codex、Cursor、Claude Code 等 AI 工具快速出前端原型，但想避免“AI 味”设计。
- 从零构建网站、落地页、后台面板，希望视觉有记忆点。
- 先通过图像生成技能定下设计方向，再自动编码实现。
- 对现有项目进行 UI 重设计审计。

## 同类对比
与 UI 库（shadcn/ui、Radix）不同，它不提供组件，而是教模型“如何组合和设计”。与 LobeChat 的设计 prompt 相比，Taste Skill 更体系化、可叠加多种风格，并支持 install 管理。与 Vercel Agent Skills 生态原生兼容，但比通用技能更聚焦前端视觉质量。

## 版本动态
默认技能已升级到 v2（实验性），大幅重写，引入设计语言推断、强制定量标准。同时保留 v1 供旧项目使用。活跃迭代中，v2 仍在实验阶段，距离稳定版还有修改。
