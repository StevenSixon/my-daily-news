## 它是什么
PenEcho 是一个支持手写输入、公式、图表和空间推理的共享 AI 画布。用户可以在无限大的画布上自由书写，AI 会根据笔迹和空间关系直接在画布上生成答案、提示或图解，省去将思维转码为文本的步骤。

## 为什么火
当前人类与 AI 的交互大多停留在文本对话框，而大量创意、学习、解题过程本质上是视觉和空间的。PenEcho 填补了这个缺口，将 LLM 与自然书写无缝结合，支持多模型后端（Claude、Codex、API），一经发布便获得 1.6k Star，体现了开发者和学习者对“视觉 + AI”模式的强烈需求。

## 技术栈
- 后端：Node.js (>=20.3)
- 前端：Canvas 渲染，支持桌面应用（Electron？待确认）
- AI 接入：支持 OpenAI Codex CLI、Anthropic Claude CLI 及 OpenAI/Anthropic 兼容 API，可配置多种模型与推理努力级别
- 配置管理：通过交互式 `penecho configure` 生成 `.env` 文件，支持多配置文件

## 核心能力
- 手写与草图识别：AI 解读笔迹、公式、图示的空间布局，给出响应
- 插件系统：v0.7.0 引入可扩展画布插件，例如图片导入（v0.7.1）
- 多模型/多后端：支持 Codex、Claude 命令行及 API 方式，灵活调整推理努力（effort）
- 推理控制：画布工具栏可实时切换推理级别（none 到 xhigh/max）
- 离线检查：非 API 来源的配置测试不消耗令牌
- 桌面与 npm 双模式：提供桌面安装包和 npm 全局安装，支持自定义端口和配置

## 适用场景
- 数学、物理等教育领域的解题与讲解
- 架构设计、思维导图、原型草图讨论
- 个人笔记与 AI 协作，将灵感直接转化为结构化的文字或图形
- 需要空间维度的头脑风暴或研究记录

## 同类对比
传统 AI 聊天工具（如 ChatGPT、Claude.ai）依赖文本输入，无法直接识别手写或空间关系。类似工程如白板 + AI 的尝试（如 Excalidraw + AI 插件）多停留在元素识别，缺乏原生手写引擎和空间推理。PenEcho 从交互底层重构了 “画布即会话” 的体验，同时支持本地 CLI 接入，隐私性更好。
