## 它是什么
PenEcho 是一个基于画布的 AI 协作工具，允许用户用手写、公式、图表进行空间化思考，AI 能读懂画布上的标记及其空间关系并直接给出答案。它通过本地 Node.js 服务将浏览器变成智能白板，支持通过 Claude CLI、Codex CLI 或自有 API Key 接入多模型，强调本地优先与隐私可控。

## 为什么火
项目解决了“聊天框无法承载非线形思考”的痛点。教育、科研、系统架构等场景中，用户常需边画边思，PenEcho 让 AI 直接理解画布上下文并就地回应，避免了将草图反复转录为文本的割裂感。其本地部署、AGPL 开源、多模型自由切换的组合，对注重控制权和自由度的极客有天然吸引力，短时间获得 1.7k Star。

## 技术栈
- **后端**：Node.js 20.3+，使用 npm 全局安装或本地开发启动。
- **前端**：浏览器端 Canvas 应用，推测使用原生 Canvas 或某画布库（README 未详述）。
- **AI 集成**：支持 Claude CLI（Anthropic）、Codex CLI（OpenAI）、OpenAI 兼容 API、Anthropic API 及 Kimi API，配置通过交互式向导完成。
- **安全**：局域网访问使用六位安全码 + 内存哈希，不存储明文。

## 核心能力
1. **画布交互**：手写、方程、图表直接铺设在无限画布上，AI 模型读取这些元素及其空间关系后生成回答。
2. **多模型后端**：统一接口接入 Claude、GPT、Codex、Kimi 等，可在工具栏按请求切换推理强度。
3. **本地离线控制**：CLI 模式下无需 API Key，通过本地已认证的 Claude/Codex CLI 使用模型，隐私数据不出机。
4. **图片与图表生成**：支持画布内搜索真实照片并插入，允许生成 Mermaid 流程图并可复制源码。
5. **桌面与团队使用**：提供桌面版下载，支持局域网多人通过密码进入同一画布（README 未详细说明实时协作特性，猜测为共享视图）。

## 适用场景
- 学生/研究者：手写解题、推导公式，AI 逐步解释并提供提示。
- 架构师/工程师：白板上绘制架构图或流程图，AI 参与讨论并直接生成 Mermaid 图表。
- 教育者：创建互动讲解画布，与远程学员同步观看。
- 极客个人：替代碎片化 AI 对话，将项目草图、思路笔记整合到统一空间。

## 同类对比
与 Excalidraw 加 AI 插件或 tldraw AI 模式相比，PenEcho 更专注于让 AI 成为画布端的“协作者”，而非简单的图生文工具。它允许多种模型混合使用，并通过 CLI 免去重复配置的繁琐。但相较于成熟的在线白板服务，它在 UI 丰富度、实时协作协议方面可能仍较初期。
