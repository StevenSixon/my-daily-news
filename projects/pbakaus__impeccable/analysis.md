## 它是什么
Impeccable 是面向 AI 编码代理（Claude Code、Cursor、Codex、Grok Build 等）的设计语言技能包。它提供一套共享的设计词汇（23 个命令）和 60 条确定性检测规则，在 AI 生成前端代码时避免落入重复的模板化设计。

## 为什么火
每个大模型都在相同的 SaaS 模板上训练，所以只要给出前端需求，AI 就会输出千人一面的设计：Inter 字体、蓝色到紫色渐变、卡片嵌套、灰色文字套在有色背景上…… Impeccable 通过**方向骰子机制**打破这种惯性，用“外部种子”决定设计方向，而不是让模型自己挑最稳妥的样式。v4 版本引入 188 个经过评审的“挑战者世界”，确保文化性强的素材胜出，贫乏的类别弱化。

## 技术栈
- 语言：JavaScript（技能/CLI 部分）
- 运行：Node.js 环境，提供 `npx impeccable` 命令
- 检测规则：60 条确定性规则可直接在浏览器扩展/CLI 运行，无需 LLM 或 API key
- 设计迭代：浏览器内决策页面、实时变体模式（`/impeccable live`）
- 多代理兼容：支持基于文件夹安装（`.claude/.codex/.cursor/.grok/.github` 等）及插件市场安装

## 核心能力
1. **一次性初始化**：`/impeccable init` 生成 PRODUCT.md 和 DESIGN.md，锁定受众、品牌、声音、色彩、字体等上下文。
2. **23 个设计命令**：`craft`、`polish`、`audit`、`critique`、`distill`、`animate`、`bolder`、`quieter`、`harden`、`delight` 等，覆盖从 UX 评审到最终润色的全流程。
3. **确定性检测器**：60 条纯规则（不依赖 LLM）检查配色、对比度、字体误用等，可在本地直接运行。
4. **方向骰子与挑战者池**：通过随机种子分配设计方向，避免重复；每次 reroll 完全清桌，不基于你拒绝的选项重述。
5. **智能作业识别**：自动判断当前是空白画布、页内新增区块、已有页面内添加、重设计或局部优化，并给予对应的自由度。
6. **反模式指南**：内置禁止清单（如禁用 Arial/Inter/系统默认字体、灰色文字配有色背景、纯黑灰色、弹性缓动等），直接融入指令。

## 适用场景
- AI 辅助前端开发团队，希望摆脱“AI 设计的 AI 味”。
- 独立开发者用 AI 编码工具搭建产品界面，想快速获得差异化设计。
- 设计能力较弱的团队，需要一套可重复执行的设计审核和润色流程。

## 同类对比
- **Anthropic 的 frontend-design skill**：Impeccable 的起点，但更强调反模板、反反复输出同样的设计套路，且增加了确定性规则检测和挑战者池。
- **常规 UI 组件库（shadcn/ui、Tailwind UI 等）**：这些是组件实现，Impeccable 是**设计方向指导层**，不提供组件代码，而是指导 AI 生成更有辨识度的外观。
- **Lint 工具（如 ESLint 之于代码风格）**：Impeccable 相当于“设计 lint”，但强在结合 AI 指令主动纠正，而非仅报告。
