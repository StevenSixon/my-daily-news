## 它是什么
一个 Claude 技能（及通用 Agent 技能），允许使用者直接向 Claude 提问任何视频内容——只需提供 URL 或本地文件。它自动执行下载、关键帧提取、音频转录（字幕/Whisper），并将画面和时间戳文字全部注入 Claude 的上下文，使模型能基于“看到”和“听到”的真实内容作答，而不是仅依赖标题或描述。

## 为什么火
* 彻底打通了 AI 与视频内容之间的最后屏障，无需手动预处理
* 支持上百个视频平台（YouTube、Loom、TikTok、X、Instagram 等）
* 零配置即可运行（首次使用时自动安装 ffmpeg、yt-dlp）
* 多种细节模式（高效/平衡/完全），平衡速度与 token 成本
* 内置帧去重算法，避免重复帧浪费算力
* 开源、MIT 协议，社区活跃（3.8k star）

## 技术栈
* Python（主控脚本）
* yt-dlp（支持数百个视频源的元数据、字幕、视频下载）
* ffmpeg（帧提取、音频处理、去重预处理）
* Whisper（Groq whisper-large-v3 或 OpenAI whisper-1）用于无字幕视频
* Claude API / Claude Code（最终解析帧与文本）
* Agent Skills 标准（兼容 50+ 宿主，包括 Codex、Cursor、Copilot 等）

## 核心能力
* **多模式帧提取**：`efficient`（仅提取关键帧，极快）、`balanced`（场景变化检测，采样到上限）、`token-burner`（不设上限，所有场景变化帧）
* **智能帧去重**：通过 16×16 灰度缩略图的平均绝对值差异，过滤近乎相同的帧，节省 token 但保留有效差异
* **双源转录**：优先使用视频平台免费字幕（yt-dlp），失败时自动调用云端 Whisper 生成时间戳文本
* **自动适配帧预算**：根据视频长度自动决定帧数上限，也支持指定时间段精准聚焦
* **多宿主安装**：Claude Code 插件、Agent Skills npx 一行命令、claude.ai web 手动导入、手动 git clone

## 适用场景
* 分析竞品或 viral 视频的开头钩子、广告创意
* 诊断用户发的屏幕录制中 Bug 出现的帧和上下文
* 长视频总结，生成带时间戳的笔记或知识库
* 快速剥离产品发布视频中的营销废话，提取实质更新内容
* 将系列教程或播放列表批量转化为可搜索的文字笔记

## 同类对比
传统手动流程（下载视频→手动截图→单独转字幕→粘贴给 Claude）完全不具备实时交互能力；YouTube 摘要工具大多只能利用标题和描述，缺乏视觉信息。本工具一次自动化完成全链路，且支持本地文件和几十个平台，深度整合 Agent 生态，远超同类脚本。
