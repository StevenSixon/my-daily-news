## 它是什么

这是一个基于 **Claude Code** 的开源求职应用框架，将 Claude 变成你的求职助理。它提供一整套结构化工作流：通过 `/setup` 建立你的个人画像，用 `/scrape` 在多国求职网站上搜索岗位，然后 `/apply` 就能自动评估匹配度、生成定制的 LaTeX 简历和求职信，甚至帮你准备面试。整个流程遵循职业指导最佳实践，但交付的是一个可编程的 CLI 管道，而不是又一个“帮我写简历”的聊天机器人。

## 为什么火

项目 2026 年 3 月诞生，短短 4 个月已收获 14.5k+ Star。**痛点精准**：求职本质上是一个高重复性的信息处理任务——阅读 JD、改简历、写求职信、跟踪结果，这些正是 LLM 擅长的事情。该框架把这些步骤自动化，但保持了完全的控制权：你 fork 后填入自己的资料，所有生成物都基于你的真实背景，而不是让 AI 凭空编造。再加上易于扩展的架构（可替换当地的求职门户、可注册自定义 LaTeX 模板），对全球求职者尤其是技术人员极具吸引力。

## 技术栈

- **Agent 运行时**：Claude Code CLI，通过 `.claude/commands` 定义自定义 slash command，`.claude/skills` 存放技能文件。
- **搜索模块**：TypeScript + Bun，预置丹麦求职门户（Jobindex、Jobnet 等）的 CLI 工具，可通过 `/add-portal` 自行扩展。
- **文档生成**：LaTeX（`moderncv` 风格简历，`cover.cls` 自定义求职信类），依赖 `lualatex` 和 `xelatex` 编译。
- **辅助工具**：Python 脚本用于薪资对标查询（需自备数据），可选的 `pdftotext` 用于 ATS 解析性检查。
- **项目组织**：纯文件驱动，所有配置和模板都在仓库内，无数据库，天然适合 Git 版本管理。

## 核心能力

1. **多源岗位聚合与初筛**：`/scrape` 搜索多个门户，去重后按匹配度排序；`/rank` 可批量打分，生成带优缺点的短名单。
2. **深度岗位匹配与材料生成**：`/apply` 执行两阶段代理工作流——先由“起草者”生成简历和求职信，再由“审稿者”批判性反馈并修订，最终输出针对性强、可直接投递的文件。
3. **个人画像强化**：`/expand` 自动扫描你在 GitHub、Kaggle 等公开主页上的信息，补充技能标签；`/upskill` 分析你的画像与岗位需求的差距，给出带学习资源的学习路线。
4. **全周期求职管理**：`/interview` 生成面试准备包（题目、STAR 案例、模拟面试）；`/outcome` 记录申请结果并归档材料，方便后续通过 `/setup` 重校准匹配框架。
5. **高度可定制**：`/add-template` 可注册你自己的 LaTeX 模板，`/add-portal` 可为任意求职网站生成新的搜索技能，底层工作流语言和国家无关。

## 适用场景

- **主动求职的技术人员**：希望摆脱为每个岗位重写简历、求职信的重复劳动，同时对生成内容质量和可控性有要求。
- **跨国求职者**：可以通过 `/add-portal` 接入本地求职市场，复用核心评估和文档生成流水线。
- **间歇性找工作的人**：项目档案化设计使得即使隔几个月再启动，也能快速从上次的申请记录中恢复状态。

**不太适合**：完全不会用命令行和 Git 的用户；对 LaTeX 排版要求极高且不愿意适配现有模板的人（虽然有 `/add-template`，但仍有上手成本）。

## 同类对比

- **Teal、Simplify 等求职 SaaS**：提供浏览器插件和在线仪表盘，但核心算法黑箱，生成内容质量参差不齐，且数据隐私受制于平台。本项目完全本地运行（除调 Claude API 外），数据自主可控。
- **通用 Agent 框架（AutoGPT / CrewAI）**：能实现类似的自动化，但需要你从零定义整个求职工作流。本项目提供了成熟可用的领域技能文件（评估框架、简历规则、LaTeX 渲染），开箱即用。
- **其他 Claude Code 技能库**：多数是片段式的“帮我写简历”提示。本项目是第一个把完整求职生命期（画像构建→搜索→申请→面试→复盘→再训练）做成结构化产品的，可重复使用、可演进。
