## 它是什么
由 BenchFlow 维护的精选、重注释的 AI Agent 评估资源列表。涵盖论文、博客、演讲、课程、工具和基准，所有条目都说明了为什么值得收录，且经过了 URL 验证和死链接修剪。

## 为什么火
Agent 评估已成为 AI 工程的核心瓶颈，但多数 “awesome” 列表只是链接堆砌。这个列表通过引文爬虫、实践者对话、47 场演讲转录和分节间隙审计，提供了 443+ 条精选链接和 146 条深度阅读笔记，信息密度远超同类。

## 技术栈
维护方式：Markdown 文档 + GitHub 协作。核心资产是 `README.md`、`PATTERNS.md`（可运行代码示例）和 `notes/` 目录的深度笔记。社区讨论在 Discord 进行。

## 核心能力
- **星级必读**：11 篇必读文章，快速入门评估体系
- **深度笔记**：对关键资源做了 146 条详细注释，标注更新状态和注意事项
- **可运行代码**：`PATTERNS.md` 提供 LLM-as-judge、pass@k、错误分析等可实操案例
- **分类覆盖**：从评估为什么需要，到具体基础设施、LLM-as-judge、Agent 特有评估、安全评估等 10+ 个主题
- **质量保证**：链接验证、死链清除、争议内容标注

## 适用场景
- 想系统学习 Agent 评估的 AI 工程师和研究人员
- 需要快速查找可靠基准/工具/论文的产品或技术负责人
- 评估系统设计者寻找架构参考和实操模式

## 同类对比
相比其他 “awesome-evals” 或 “awesome-llm” 列表，本项目不做链接垃圾场，所有条目都经过人工验证和注释，并提供了可直接使用的代码示例，弥补了学术与实践之间的鸿沟。
