## 它是什么

Hermes Browser Extension 是一个 Chrome/Edge/Chromium 侧边面板，专为 Nous Research 的 Hermes Agent 打造。它不自己跑模型，而是直接连接你本地的 Hermes API 服务器（或远程），将当前浏览器页面的内容（文本、选中文字、开放标签等）作为上下文实时注入 Agent，让 Agent 像有了“浏览器的眼睛”。

## 为什么火

- **本地优先、隐私友好**：默认连接本地 `127.0.0.1:8642`，所有数据留在你的机器上，不用把网页丢给云端。
- **无缝集成 Hermes 生态**：同步 Hermes 里的模型、会话、技能、配置文件，配合运行时工具条，让 Agent 不仅读网页，还能调用其他 MCP 工具。
- **极客友好**：纯开源 MIT，不依赖云服务，按需自建、自控，适合想把浏览器变成 Agent 交互入口的开发者。

## 技术栈

- JavaScript（构建工具链基于 npm）
- Chrome Extension Manifest V3，利用 Side Panel API 做侧边栏
- WebSocket 用于远程仪表盘模式，REST API 用于本地/远程 API 服务器
- 代码结构包含 extension 核心、浏览器上下文协议模块、诊断/兼容性面板等

## 核心能力

- **浏览器上下文注入**：抓取页面可读文本、元数据、标题、表单、链接、按钮，包装成 `untrusted context` 发送给 Hermes。
- **上下文模式灵活切换**：仅聊天、跟随标签、固定标签、选择开放标签。
- **语音听写**：优先使用 Hermes STT，回退到浏览器语音识别。
- **实时工具活动条**：流式显示 Agent 的工具调用（如 `/summarize`），而不是原始 `[tool]` 标记。
- **主题与系统兼容**：6 款主题 + 亮/暗/系统模式。
- **兼容性矩阵**：自动检测网关版本，降级到仅聊天模式，避免 API 报错。
- **诊断报告**：一键拷贝安全诊断（浏览器、网关、能力标记、最后错误等）。
- **无浏览器控制权限**：v0.1.9 不支持点击、输入、表单提交、下载等操作，安全保守。

## 适用场景

- 本地 AI 辅助浏览：总结、解释、重写页面内容、提取行动项。
- 开发者日常：将网页文档或 API 文档放进 Hermes，结合自定义技能生成代码。
- 多标签页管理：让 Agent 感知多个打开页面的上下文。
- 自托管 AI 工作流：配合 Hermes 的社交/消息插件，把网页信息和社交信息融合。

## 同类对比

- **ChatGPT 浏览器扩展 **：强依赖云端，数据隐私是个问号；Hermes 扩展本地运行，上下文不离开你的网络。
- **Copilot in Edge**：深度集成 Edge，但模型限定、不可自托管；Hermes 允许你接入任何 Hermes 支持的模型。
- **Bardeen / ui.dev 等自动化扩展**：偏向工作流自动化，Hermes 是 Agent 感知入口，不是操作型。
- **本地优先的网页助手**：很少有打通本地 Agent 与浏览器上下文的开源方案，Hermes 填补了这个空白。
