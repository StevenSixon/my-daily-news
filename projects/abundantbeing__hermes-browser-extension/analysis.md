## 它是什么
Hermes 浏览器扩展是一个 Chrome/Edge/Chromium 侧边栏，将当前网页的标题、URL、可读文本、选区、表单、链接等上下文安全发送到本地或远程的 Hermes Agent 运行时。它不是独立聊天机器人，而是 Hermes Agent 的浏览器端专属交互入口。

## 为什么火
Hermes Agent 社区急需一个能直接利用网页上下文的轻量工具，避免手动复制粘贴。该扩展以本地优先、权限最小化（无调试器、无nativeMessaging、无浏览器操控权限）作为卖点，适合对隐私和自托管要求高的极客用户，且代码开源、本地构建加载，信任感强。

## 技术栈
- Chrome Extension Manifest V3，Side Panel API
- 纯 JavaScript/Node.js 构建（需 Node.js 20+）
- 通信：默认连接 `http://127.0.0.1:8642` 的 Hermes API 服务器，支持远程 HTTP/HTTPS 或 OAuth WebSocket 模式
- 权限极简：仅 activeTab、storage、sidePanel、webRequest 等必要权限，无 cookies/history/downloads
- 支持 Light/Dark 多主题

## 核心能力
- 自动捕获活动标签页的标题/URL、正文文本、选区、表单、链接等上下文
- 支持“仅聊天”“跟随活动标签”“固定标签”等上下文范围模式
- 将上下文包装为“不可信内容”后发送，提升安全性
- 与 Hermes 的工具、技能、记忆、MCP 服务器无缝集成
- 流式响应、工具调用活动可视化、上下文用量指示器
- 语音输入支持（Hermes 转录或浏览器回退）
- 主题与外观定制
- v0.1.8 新增：运行中提示词转向、模型路由渲染、精确上下文计量、工具调用实时流

## 适用场景
- 已有 Hermes Agent 的用户，需要基于当前网页快速提问、总结、解释或执行复合任务
- 研究/写作时，利用边栏实时参考网页内容调用本地模型或技能
- 隐私敏感环境下用本地运行模型处理网页内容，无需将数据发往第三方
- 开发者调试或构建基于网页上下文的自动化工作流

## 同类对比
与通用浏览器 AI 侧栏（如 Sider、Monica）不同，Hermes Browser Extension 完全依赖自托管的 Hermes Agent，数据不出本地网络，不依赖云端大模型厂商 API，更适合自建智能体生态的“硬核”用户。无需额外的桌面软件或浏览器注入，权限极小，安全可控。
