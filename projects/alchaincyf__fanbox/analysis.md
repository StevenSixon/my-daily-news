## 它是什么
FanBox 是一个 macOS 桌面的 Coding Agent 驾驶舱，将文件浏览、内嵌终端、原地预览整合为一个窗口，用于找回被 AI 生成的大量项目、运行 Claude Code/Codex 等 coding agent，并实时观察 agent 改动了哪些文件。

## 为什么火
在 vibe coding 浪潮下，开发者一个下午能让 AI 生成十个项目，但之后难以管理和回溯。FanBox 精准切入「找回 + 预览 + 轻改 + 指挥 agent」链路，填补了 Finder、终端、编辑器之间的 workflow 空白，获得 885 Star，社区自发移植 Windows。

## 技术栈
- **前端与桌面壳**：Electron，零构建运行时
- **文件管理**：本地文件系统操作，支持模糊搜索和全文搜索
- **终端**：node-pty + xterm.js（WebGL 渲染，支持语文宽字符）
- **编辑器**：Monaco（代码/JSON）、Milkdown Crepe（Markdown 所见即所得）
- **测试/验收**：Playwright 自动化截图与断言
- **平台**：macOS Apple Silicon 原生，签名公证，Windows 社区移植

## 核心能力
- **文件找回与预览**：全局模糊搜索 `⌘K`，强色实体图标，Markdown/HTML/图片/视频/PDF 原地预览，项目徽章自动识别类型。
- **Agent 改动可视化**：活的仪表盘显示文件变动涟漪，跟随模式实时跟踪 agent 编辑，会话回放时间轴，变更收件箱跨项目汇总，Git diff 并排对比。
- **Agent 驾驶舱**：项目记忆（历史会话、续上上下文），截图直通车喂给 agent，AI 整理提案，发版向导，Skills 透视，Agent 用量统计，磁盘占用透视。
- **真实终端**：可拖入文件/文件夹，路径可点击打开，选中即甩给终端，态势感知提示，内置 11 种 agent 一键启动（Claude Code、Codex 等）。
- **所见即所得编辑**：Markdown、代码、图片标注均支持原地编辑，未保存守卫。
- **三套完整皮肤**：配色、字体、图标、代码高亮、终端主题整体切换。

## 适用场景
- 频繁使用 Claude Code、Codex 等 coding agent 生成项目的 AI 开发者
- 需要同时管理多个快速迭代的 AI 项目的独立开发者
- 希望摆脱 Finder+终端+浏览器频繁切换的低效工作流的人群
- 对本地优先、无云依赖有要求的用户

## 同类对比
- **VS Code + 终端**：编辑能力更强大，但缺少文件找回、agent 改动追踪、仪表盘等一站式体验，窗口切换频繁。
- **Finder + iTerm**：原始工具组合，零集成，需手动定位项目和观察改动。
- **Warp / iTerm2**：终端功能出色，但无文件管理、预览、agent 集成。
- **Hyper Terminal**：插件化终端，无文件管理。
- **专业文件管理器**（如 Marta、Forklift）：文件操作强大，但无内嵌终端和 agent 面板。
FanBox 的独特优势在于将“找回 + 运行 agent + 观察改动”闭环，而非单纯替代某类工具。
