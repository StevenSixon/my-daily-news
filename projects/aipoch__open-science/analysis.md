## 它是什么
Open Science 是一个开源、模型无关的 AI 科研工作台，以本地桌面应用形式提供。核心是“计划-执行”代理，搭配持久化的沙盒计算内核（Python/R），在一个项目内整合会话、文件、代码、结果和活动历史，让研究过程可审查、可复现。

## 为什么火
科研工作常被分散在聊天窗口、笔记本、本地脚本和文献库之间，上下文割裂。Open Science 把整个流程拉回一个本地工作区，且不锁定模型——用户可以自由选择内置云模型、自建兼容网关，甚至使用已有的 Claude 或 ChatGPT 订阅。开源 Apache-2.0 许可，无座位费，吸引重视自主可控的研究团队。

## 技术栈
- 语言: TypeScript
- 架构: 桌面应用（具体跨平台框架未在 README 中说明，推测为 Electron）
- 计算内核: 内置沙盒化的 Python 与 R 执行环境，支持 Notebook
- 模型接入: 多提供商适配器，支持 Anthropic 兼容网关、Claude 订阅、ChatGPT/Codex 订阅，模型能力自动映射
- 技能与连接器: 基于 SKILL.md/zip/.skill 包的技能系统，内置生命科学数据连接器（基因、蛋白、变异、临床等），支持 MCP 扩展

## 核心能力
- **项目-任务-会话持久化**: 每个项目保存会话记录、上传文件和生成成果，重启不丢失
- **代理执行与审批**: 代理可读文件、运行代码、搜索网页、调用科学数据连接器，所有危险操作需用户审批
- **模型无关**: 支持多模型提供商，并根据真实能力映射推理努力度
- **科学技能生态**: 内置技能目录，允许用户创建、导入、预览技能包，代理也可请求安装
- **丰富的预览**: PDF 清晰渲染与缩放，office 文档、图像、分子结构等原生预览
- **权限控制**: 每个工具可设置总是允许/每次询问/阻止，普通语言权限卡展示

## 适用场景
- 科研人员快速探索假设，获取包含代码、图表和引用报告的完整记录
- 生信分析：借助内置的生命科学连接器查询公共数据库，在本地安全处理敏感数据
- 教学环境：提供可重复的研究工作流，学生可审核每一步推理和计算
- 团队协作（未来可能扩展）：目前单机使用，但项目文件可共享

## 同类对比
- **Jupyter AI / Colab**: 侧重笔记本式计算，Open Science 增加了持久化项目、代理规划和多模型切换，且全部本地运行
- **Deepnote / Hex**: 云协作平台，Open Science 为本地优先，数据隐私更强，无供应商锁定
- **ChatGPT / Claude Code**: 会话式，缺乏持久化项目结构和计算内核集成，Open Science 把对话、代码与结果放在一个统一工作区
