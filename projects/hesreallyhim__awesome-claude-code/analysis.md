## 它是什么
一个手工维护的 `awesome` 列表，专门收集 Claude Code（Anthropic 出品的命令行编程助手）相关的技能、插件、状态行、开发工具、学习指南与多代理编排资源，面向初学者与资深用户。

## 为什么火
Claude Code 作为目前统治级的 AI 编码伴侣，社区产出爆发式增长；该列表以“质量、安全、原创性”为筛选标准，提供分类清晰、持续更新的入口，减少信息过载。5 万星见证其社区认可度。

## 技术栈
本仓库仅为 Markdown 组织的精选列表，非可执行代码。列表内资源覆盖 Python/Node/Shell 等，涉及 Claude Code 插件机制、MCP 协议、Hook 系统、Agent 模式等。

## 核心能力
- **快速上手**：提供 Claude Code 思维模型、CLAUDE.md 写法、hooks 等核心概念的单页指南与交互教程。
- **官方资源直达**：直接关联 Anthropic 官方 skills 仓库、最佳实践、安全审查 Action 等。
- **生态扩展**：收录状态行、远程控制、语音 I/O、替代客户端、设计/写作/创意媒体等垂直领域工具。
- **深度工具链**：覆盖多代理编排、技能库、记忆与上下文持久化、用量监控、可观测性与代码检查。

## 适用场景
- 刚开始使用 Claude Code 的开发者寻找最佳实践和配置模板。
- 资深用户探索高级用法（hooks、技能、多代理、CI 集成）。
- 团队负责人评估如何在项目或 CI/CD 中标准化 Claude Code 使用。

## 同类对比
与通用 AI 工具列表（如 `awesome-chatgpt`）不同，本列表专精 Claude Code 生态，且刻意强调“代码质量与安全”，避免低价值资源泛滥。其“当前迭代”侧重新资源，对旧资源有保留策略。

## 版本动态
当前列表以高亮非“旧版”资源为目标，宣布后续将陆续补回仍维护的“遗留资源”；仓库近期仍在活跃更新（最后推送 2026-07），保持高时效。
