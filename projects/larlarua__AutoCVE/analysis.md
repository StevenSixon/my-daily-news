## 它是什么
AutoCVE 是一个基于多智能体（Multi-Agent）协作的自动化 CVE 挖掘平台，能够从仓库导入、源码审计、漏洞验证到生成中/英 CVE 报告，提供一键式操作。整个流程由 Orchestrator 调度 Recon、Scan、Triage、Finding、Verification 等多个专用 Agent，深度结合 LLM 的推理能力与 SAST 工具扫描，实现比纯规则扫描更高的漏洞发现深度和可信度。

## 为什么火
项目在发布一周内即发现 30 个真实 CVE，覆盖 14 个知名开源项目（含 Chartbrew、Lemmy、typebot.io 等），最高 CVSS 评分 9.9。它将复杂的渗透测试与代码审计工作流产品化，大幅降低了从源码到 CVE 申报的技术门槛，同时保持自托管、可扩展的架构，吸引了大量白帽和安全工程师关注。

## 技术栈
- 后端：Python 3.11+，FastAPI，PostgreSQL 15
- 前端：React 18
- 编排：Multi-Agent 架构，ReAct Loop 状态机
- 部署：Docker Compose，GHCR 预构建镜像
- License：AGPL-3.0

## 核心能力
- **一键 CVE 挖掘**：项目筛选→仓库导入→审计任务创建→多 Agent 协同挖掘→漏洞入库与报告生成。
- **三模式审计**：增强扫描（工具+误报过滤）、智能审计（深度源码分析，适合CVE）、综合审计（工具+深度分析全覆盖）。
- **Finding Agent**：面向 CVE 挖掘设计的核心智能体，结合 ReAct Loop、工具编排、Nudge 纠偏机制，产出结构化漏洞证据。
- **交互式审计 & 过程追踪**：支持审计中与用户对话追问，可视化 Agent 执行树与工具调用日志。
- **漏洞管理 & Skills 扩展**：自动去重入库，支持给不同 Agent 配置专属 Skills 扩展能力边界。

## 适用场景
- 安全研究员批量挖掘开源项目未知漏洞（0day / CVE）
- 企业安全团队对内部代码库进行自动化深度审计
- 渗透测试人员快速验证和输出漏洞报告
- 教育场景中学习基于 LLM 的漏洞挖掘与验证流程

## 同类对比
相较于传统规则型 SAST 工具（如 Semgrep、CodeQL），AutoCVE 的优势在于引入多 Agent 协作与 LLM 推理，能对复杂逻辑漏洞（如访问控制绕过、SSRF、授权缺失）进行上下文关联和动态验证，并直接生成符合 CVE 申请格式的报告。劣势是依赖外部 LLM API（需自行配置），且未提供与传统工具的定量误报/漏报对比数据。
