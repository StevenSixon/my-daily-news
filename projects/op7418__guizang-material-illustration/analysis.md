## 它是什么

这是一个适配 Claude Code、Codex 等 Agent 环境的 **Skill**，用于将文字概念、截图图表、产品机制、教学素材等转化为 **材质化 3D 插图**，并且图内可以直接包含中文标签、箭头、数据标注。它与作者的另一个项目 `guizang-social-card-skill` 配套：本 Skill 负责中心配图，Social Card Skill 负责卡片版式。

核心定位：不是生成一张看不懂的漂亮装饰图，而是生成能"把意思讲清楚"的中心图。

## 为什么火

- **填补了图文生产中的空白**：很多人知道需要配图，但找不到合适的工具快速生成有解释力的图。
- **Agent 原生集成**：一条命令安装到 Claude Code/Codex 中，用自然语言驱动生成，门槛极低。
- **图内可以有中文字**：突破了以往图像生成工具中文崩坏的痛点，明确宣称支持短标签、箭头、图例。
- **解决真实场景**：文章配图、工作汇报、学术解释、数据图表美化，场景明确，方法具体。
- **与排版 Skill 联动**：生态化思路，不是孤立工具。

## 技术栈

- **载体**：Agent Skill，通过 `SKILL.md` 定义触发条件和工作流程
- **依赖**：需要 Agent（Claude Code/Codex）具备 shell 权限和图像生成能力（调用 GPT-Image 或 imagegen 等）
- **安装**：通过 `npx skills add` 或 git clone 到 `~/.claude/skills/`
- **配置**：参考文件（`references/`）包含视觉风格、提示词模式、图表美化规则、QA 检查等，作为 Agent 的上下文指令
- **生成模型**：README 未限定具体模型，由 Agent 可用的图像生成能力决定

## 核心能力

1. **解释图**：把抽象概念、流程、机制、系统关系画成带标签的图
2. **图表美化**：从截图或原始数据中抽取语义，重新生成材质化图表（柱状、折线、甘特、桑基等）
3. **参考辅助出图**：遇到冷门概念、品牌、科学装置时，先查参考信息再统一风格生成
4. **图内文字**：支持短中文标签、箭头、数据标注直接生成在图片中
5. **多题材支持**：教育（物理、生物）、人文（诗歌、历史）、工作汇报、产品机制等
6. **QA 优先**：交付前检查中文标签正确性、数据准确性、裁切、社交卡片尺寸下的可读性

## 适用场景

- 文章/公众号/知识库的配图
- 产品功能机制图、架构图
- 工作周报的状态配图（进展/风险/决策）
- 教学课件的科学机制图
- 社交媒体卡片的中心图（与 Social Card Skill 联动）
- 图表截图的美化重绘
- 冷门概念的可视化解释

## 同类对比

- **通用文生图工具（Midjourney, DALL·E 等）**：可以生成精美图片，但不擅长添加中文解释性标签，且缺乏对 Agent 工作流的深度整合。
- **Napkin.ai 等智能配图工具**：虽可生成图表和插图，但生态弱，与 Agent 编辑器集成度低。
- **其他 Agent Skill**：目前鲜有专门针对"材质风带字解释图"的 Skill，且本项目的参考文档详尽，提供了从提示词模板到 QA 检查的完整流程。
- **对比同类卡片/排版 Skill**：本项目明确分工为"中心图"，而不是整张卡片，与卡片排版 Skill 形成互补。
