## 它是什么
Orca 是一个供开发者并行管理多个 AI 编码代理（Claude Code, Codex, Grok, Cursor 等）的 Agent Development Environment (ADE)。每个代理运行在独立的 git 工作树（worktree）中，你可以在桌面或手机端监控、输入指令，甚至让代理互相对比产出。

## 为什么火
29k+ 星、YC 背景，核心卖点是「用你自己的 API 订阅」「不做代理本身的包装」，而是让现成的 CLI 代理在统一环境里并发执行。移动伴侣 App 和 WebGL 级终端提升了操控体验，吸引了需要同时跑多个代理的重度开发者。

## 技术栈
- 语言：TypeScript
- 终端渲染：WebGL（类 Ghostty 终端，支持无限分割、持久回滚）
- 桌面端：跨平台（macOS / Windows / Linux），推测基于 Electron
- 移动端：原生 iOS（TestFlight） / Android（APK）
- 远程：SSH 远程工作树
- CLI：提供 `orca` 命令行工具用于脚本化操作
- 授权：MIT

## 核心能力
- 并行工作树：一键分派同一提示到多个代理，各自在独立的工作树中运行，事后对比并合并最优结果
- 移动伴侣：从手机查看代理进度、发送后续指令或接收完成通知
- 终端分割：WebGL 终端支持无限分屏，滚动历史持久化
- 设计模式：在嵌入式 Chromium 中点选 UI 元素，自动提取 HTML/CSS/截图送入代理提示
- GitHub & Linear 原生集成：直接在应用内浏览 PR、Issue 或项目板，从任务启动工作树
- SSH 远程工作树：在远程机器上运行代理，带自动重连和端口转发
- AI 差异注释：对代理生成的 diff 行添加评论并反馈给代理
- 拖放文件到代理：支持将文件或图片直接拖入代理提示框
- Orca CLI：使用命令创建工作树、截图、点击、填写表单，方便自动化
- 支持任意 CLI 代理（已适配 20+），账户切换与用量追踪内建

## 适用场景
- 需要同时用多个 AI 编码代理尝试不同方案，然后比较质量的开发者
- 远程 VPS 上跑代理，本地机器仅作为操控界面
- 需要移动端随时跟进代理工作的场景（如在通勤时检查任务状态）
- 想要脚本化代理工作流（CI 中调用 Orca CLI）的团队

## 同类对比
不同于 IDE 插件（Continue、Cody 等），Orca 不改造单个代理体验，而是提供多代理编排层。与 open-interpreter 或单个 CLI 代理相比，核心区别在于**隔离并发**和**结果对比**，目前无直接竞品。
