## 它是什么
Orca 是一个 **Agent Development Environment (ADE)**，可以同时编排多个 AI 编码代理（如 Claude Code、Codex、OpenCode 等），每个代理运行在独立的 git worktree 中，提供统一的桌面、移动和 VPS 界面。用户使用自己的 API 订阅，完全掌握成本与隐私。

## 为什么火
仓库 30k+ stars，YC 支持，解决了开发者“单代理太慢、取舍困难”的痛点。它允许 fan-out 同一个 prompt 到多个代理，自动隔离文件变更，直接对比结果并选择最优，把代理竞赛变成了日常流程，而非一次性实验。

## 技术栈
- **前端**: 桌面版基于 Electron，集成 Ghostty 级 WebGL 终端、Chromium 内嵌浏览器
- **代理集成**: 通用 CLI 代理适配，任何能在终端运行的工具都可接入
- **编排层**: 原生 git worktree 管理、会话持久化、SSH 远程执行
- **语言**: TypeScript

## 核心能力
- **并行工作树**: 一句话同时启动多个代理，各自修改隔离分支，最终合并优胜者
- **移动伴侣**: iOS/Android 端可监控代理状态、发送跟进指令
- **设计模式**: 在真实 Chromium 窗口中点击 UI 元素，自动将 HTML/CSS/截图喂给代理
- **GitHub/Linear 原生集成**: 在应用内浏览 PR、任务，一键从素材创建工作树
- **SSH 工作树**: 在远程机器上运行代理，自动重连与端口转发
- **AI Diff 批注**: 在差异行上评论并回传给代理，形成迭代式 review 循环
- **Orca CLI**: 允许脚本驱动工作树创建、快照、模拟点击等，让代理也能操控 IDE

## 适用场景
- 快速对比多个 AI 编码方案，例如同时让 Claude Code 和 Codex 解决同一 Bug，挑选修复更完善的版本
- 在远程算力强大的服务器上运行代理，本地只做监控
- 移动场景下随时查看代理进度，发送简短指令
- 与 GitHub/Linear 深度集成的工作流，减少上下文切换

## 同类对比
与 VS Code + Copilot、Cursor 等单代理工具相比，Orca 的重点是**并行、隔离、竞赛**，而不是单个代理的深度体验。它更适合需要对多个 AI 输出进行严格比较和合并的团队，或是希望最大化利用不同模型优势的开发者。开源、本地运行、自带移动端也是区分点。

## 版本动态
项目更新极其频繁（每日多次 release），最新 v1.4.159 包含多项稳定性修复：持久化状态 fsync 化保证不丢数据、Windows PTY 身份判空防护、移动端连接断开恢复、性能优化（减少 relay 快照）、以及 sidebar 工作树可视化增强等。
