## 它是什么
Orca 是一个面向专业开发者的 AI 智能体编排环境（ADE），核心是在一个桌面应用中并行驱动多个命令行 AI 编码代理，每个代理运行在隔离的 git worktree 中，允许用户比较结果并选择最佳输出。它同时提供 iOS/Android 移动伴侣、WebGL 终端、嵌入式 Chromium 浏览器（设计模式）、GitHub/Linear 原生集成等。

## 为什么火
- 让多个 AI 代理同时处理同一任务成为日常操作，解决了单一模型结果不确定的问题。
- 兼容任意 CLI 代理，无需厂商适配，用户自带订阅密钥即可使用，无平台绑定。
- 终端体验对标 Ghostty，开发体验对标 VS Code，且每天频繁发布新功能，社区活跃（Discord/X），YC 投资背书。

## 技术栈
- 主语言：TypeScript（基于 Electron 的桌面应用）
- 终端渲染：WebGL
- 工作区隔离：git worktree
- 移动端：iOS（Swift/可能）和 Android APK
- 自动化：内置 Orca CLI（`orca worktree` 等命令）

## 核心能力
- **并行 Worktree**：一键将提示词广播至多个代理，各代理在克隆的 git 分支中独立工作，最终可合并差异。
- **多代理支持**：已测试 Claude Code、Codex、Grok、Cursor、Copilot、OpenCode、Pi 等二十余种 CLI 代理。
- **移动伴侣**：通过手机监控代理进度、收到通知、发送后续指令。
- **设计模式**：直接在嵌入式 Chromium 中点选 UI 元素，将 HTML/CSS/截图注入代理提示词。
- **SSH 远程**：支持在远程机器上运行代理，自动重连和端口转发。
- **终端分割**：无限分屏、WebGL 加速、滚动回放持久化。
- **GitHub/Linear 集成**：应用内浏览 PR、Issue，从任务直接创建工作树。
- **Orca CLI**：可脚本化控制工作树、截图、点击等，让代理自主操作 Orca。

## 适用场景
- 探索性编程：向多个模型抛出相同需求，快速收敛到最佳实现。
- 代码审查：将 PR 分发至不同代理分析，汇总反馈。
- 前端迭代：利用设计模式让代理精准理解 UI 上下文。
- 远程开发：在云端机器编排代理，本地仅做监工。

## 同类对比
- **Open Interpreter / Aider**：后者主要是单会话 CLI 代理，Orca 是多代理并行协调器，提供 GUI 与移动端。
- **Cursor / Windsurf**：IDE 向的单代理集成，Orca 明确不做 IDE 补全，而是代理编排平台。
- **LangChain / CrewAI**：框架级别，需要代码定义协作逻辑；Orca 通过工作树和终端直接让人工参与，更贴近“浏览器多标签”的直观体验。
