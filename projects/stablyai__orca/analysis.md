## 它是什么
Orca 是一个面向 100 倍开发者的 AI 智能体编排器（ADE）。它将多个 CLI 编码代理（如 Claude Code、Codex、OpenCode、Pi 等）汇聚在同一界面中，允许你在隔离的 git worktree 中并行运行它们，相互对比结果后选择最佳方案合并。其桌面应用提供了现代化的终端、代码审查、浏览器设计模式等一体化工作流，移动伴侣让你在手机上也能监控和指挥代理。项目由 YC 支持，MIT 许可，创建仅四个月已获 1.2 万星。

## 为什么火
随着推理型编程助手的爆炸式增长，开发者常需要同时尝试多种模型或不同提示策略。Orca 打破了单一代理的限制，提供了一种“智能体竞技场”，让你轻松对比输出，减少来回切换的摩擦。它的移动端通知和远程操控特性也吸引了注重效率和灵活性的用户。频繁的每日迭代与社区活跃度进一步推高了热度。

## 技术栈
- **语言**: TypeScript
- **桌面框架**: 推测为 Electron（支持 macOS、Windows、Linux）
- **终端渲染**: 基于 Ghostty 的 WebGL 技术，支持无限拆分和持久滚动
- **隔离机制**: 利用 git worktrees 为每个代理创建独立的沙箱工作目录
- **移动端**: iOS 和 Android 原生应用（TestFlight 和 APK 提供）
- **集成**: GitHub API、Linear API、SSH 远程连接
- **CLI**: 内置 `orca` 命令行工具，可脚本化所有操作

## 核心能力
- **并行工作树**: 一次提示可扇出至多个代理并发运行，各自拥有独立 git worktree，完成后可选择最佳输出合并。
- **移动伴侣**: iOS/Android 应用，实时查看代理进度，发送跟进指令，接收完成通知。
- **终端拆分**: Ghostty 级 WebGL 终端，支持无限拆分、持久滚动和重启后恢复。
- **设计模式**: 在嵌入式 Chromium 窗口中点击 UI 元素，自动提取 HTML/CSS 和截图发送给代理。
- **原生 GitHub/Linear**: 浏览 PR、Issue，从任务一键创建工作树，审查或提交代码无需切换窗口。
- **SSH 工作树**: 在远程服务器上运行代理，支持自动重连和端口转发。
- **注释 AI 差异**: 在 diff 行上直接添加注释并发送回代理，方便审查与迭代。
- **拖拽与编辑**: 类似 VS Code 的编辑器，支持拖放文件或图片到代理提示中。
- **Orca CLI**: 命令行脚本化，可创建 worktree、截图、模拟点击等。
- **其他**: 快速搜索、账户切换与用量追踪、Computer Use 模式、通知与未读状态等。

## 适用场景
- 同时对比多个 AI 编码助手（如 Claude Code vs. Codex）解决同一问题。
- 远程开发与多任务并行，手机上监督长时间运行的任务。
- 团队代码审查流程：代理生成代码，人工在 Orca 中注释并迭代。
- CI/CD 集成：通过 CLI 自动化代理操作。
- 前端开发：利用设计模式快速调整 UI 并获取 AI 建议。

## 同类对比
与单一助手 IDE（如 Cursor、GitHub Copilot）相比，Orca 更侧重于**编排多个代理**而非提供单个内联补全，本质上是“代理的多路复用器”。类似的多代理工具（如 Open Interpreter 或 Aider）通常仅捆绑特定后端，而 Orca 无代理锁定，用户可自由选择任何 CLI 工具。与纯粹的终端复用器（如 tmux）相比，Orca 提供了专为 AI 工作流设计的 UI 和移动端访问，且内置 git worktree 隔离。
