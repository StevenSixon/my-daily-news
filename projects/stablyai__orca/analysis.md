## 它是什么
Orca 是一个面向开发者的 AI 代理编排桌面应用，让你在统一的图形界面中同时运行多个 CLI AI 编码代理（如 Claude Code、Codex、OpenCode），每个代理运行在独立的 Git 工作树中，支持移动端监控和远程 SSH 执行。

## 为什么火
Star 数接近 30K，获 YC 支持。开发者渴望用一个工具管理多个不同的 AI 编码助手，避免“终端地狱”，同时利用并行工作树进行迭代实验，Orca 正好填补了这一空白。它不绑定任何模型，只编排，符合开源、多代理的趋势。

## 技术栈
- TypeScript 编写（桌面应用 + 移动端）
- 终端渲染基于 WebGL，提供 Ghostty 级性能
- 支持 macOS、Windows、Linux 桌面，iOS 和 Android 移动端
- 内嵌 Chromium，用于设计模式的元素选择与截图
- 集成 Git 工作树、SSH 远程、GitHub/Linear API
- 提供 Orca CLI 进行脚本化控制

## 核心能力
- **并行工作树**：一键将同一提示派发到多个代理，各自在独立 Git 分支运行，比较结果后合并最优。
- **移动伴侣**：通过 iOS/Android 应用接收代理完成通知并发送跟进指令。
- **终端分割**：提供高性能无限分割的终端，支持 WebGL 滚动回看。
- **设计模式**：点击浏览器 UI 元素，自动提取 HTML/CSS/截图注入代理上下文。
- **GitHub/Linear 原生集成**：在应用内浏览 PR/Issue，从任务直接创建工作树。
- **SSH 远程执行**：在远程机器上运行代理，自动重连和端口转发。
- **注释 AI 差异**：在 diff 上添加评论并反馈给代理，形成审查循环。
- **拖放文件**：将文件或图片直接拖入代理提示。
- **Orca CLI**：允许脚本化工作流，包括创建 worktree、快照、点击、填充等操作。
- **账户切换与用量追踪**：统一查看各代理的用量和速率限制，无缝切换 API 密钥。
- **支持任意 CLI 代理**：只要能在终端运行，就能在 Orca 中运行，已列出 20+ 支持的代理。

## 适用场景
- 需要同时评估多个 AI 编码代理（如 Claude Code vs. Codex）的开发者。
- 希望用同一套代码库并行实验不同实现方案，并在独立分支中隔离影响的团队。
- 在移动状态下监控长时间运行的代理任务并及时干预。
- 远程利用高配服务器跑代理，本地只做显示和控制。
- 自动化工作流：使用 CLI 编排多个代理完成复杂 CI/CD 步骤。

## 同类对比
- **vs. AI IDE（Cursor, Windsurf）**：Orca 不是 IDE，不提供代码编辑增强（虽然内嵌了编辑器），而是代理编排器，让你使用已有终端代理，保留原有工作流。
- **vs. 终端复用器（tmux, screen）**：Orca 增加了 Git 工作树管理、移动通知、代理特定集成和 UI，比纯终端更易管理大量并行代理。
- **vs. 单一代理的 GUI 包装**：Orca 可以同时运行不同公司的代理，不锁定生态。
