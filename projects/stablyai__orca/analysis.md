## 它是什么

Orca 是一款 **AI 代理编排环境 (ADE)**，专为高强度建造者设计。它不提供模型，而是将任何 CLI 编码代理（Claude Code、Codex、OpenCode、Pi 等）跑在独立的 Git 工作树中，通过统一的桌面和移动界面进行管理、监控、对比与合并。一句话：把 AI 代理当成可以并行分身的开发队友，你只需发号施令。

## 为什么火

- **多代理并行试错**：一个 Prompt 分发给多个代理，同时工作在不同分支，能直接对比结果，选中最好的合入。
- **自带密钥省钱**：支持用户自己的 API 订阅，避免中间商赚差价，且账户热切换。
- **全链路闭环**：从查看 GitHub/Linear 任务、分派代理、审查 diff、注释反馈到合并，无上下文切换。
- **移动端原生**：手机可以随时查看代理进度、补充指令，打破必须守在桌面前的局限。

## 技术栈

- 核心语言：TypeScript
- 终端渲染：WebGL 驱动的 Ghostty 级终端，支持无限分屏和会话持久化。
- 桌面框架：疑似 Electron（存在 ConPTY、WebGL Context、Chromium 内嵌浏览器等关键词）。
- 平台覆盖：macOS、Windows、Linux 桌面端 + iOS/Android 移动端。
- 代理接口：任何 CLI 工具均可在其终端中运行，无需额外适配。

## 核心能力

- **并行工作树**：每个代理独占一个 Git worktree，不同任务隔离，允许同时开发多个功能。
- **移动伴侣**：手机接收代理完成通知、查看进度、发送后续指令。
- **终端艺术**：WebGL 高性能终端，无限分割，历史可跨会话保留。
- **Design Mode**：从内嵌 Chromium 窗口中点击任意 UI 元素，直接将其 HTML/CSS 和高亮截图塞进代理的上下文。
- **原生集成 GitHub & Linear**：在应用内浏览 issue/PR，从任务直接创建工作树并指派代理。
- **SSH 远程**：在远端强机上运行代理，带自动重连和端口转发。
- **Diff 注释**：直接在 AI 生成的 diff 上留言，自动发回给代理迭代。
- **拖拽即上下文**：从文件树拖动文件或图片到代理提示词。
- **Orca CLI**：通过 `orca` 命令让脚本控制代理工作流，实现更高自动化和 Computer Use（调用桌面应用）。

## 适用场景

1. **多方案快速PoC**：对一个需求，让 Claude Code 和 Codex 分别实现，择优合并。
2. **远程开发与 CI 集成**：用 SSH 将代理跑在服务器上，配合通知随时参与评审。
3. **跨平台移动指挥**：人在通勤，用手机检查代理进度，临时增加新的需求点。
4. **强上下文工程**：Design Mode 直接抽取界面元素，省去手动复制粘贴 HTML。

## 同类对比

- **VS Code/Cursor 等 IDE**：它们是单代理、单会话的代码辅助；Orca 是多代理的调度中心，相当于给每个代理分配一个沙盒式终端。
- **传统终端复用器 (tmux)**：只能手动切分窗口，无代理状态追踪、无移动端、无 diff 注释。
- **任务管理工具 (Jira/Linear)**：不直接驱动代理，Orca 将任务跟踪与代理执行缝合在同一界面。
- **自建代理调度平台**：Orca 为本地优先、零配置，用你已有的终端代理和个人 API 密钥即开即用。
