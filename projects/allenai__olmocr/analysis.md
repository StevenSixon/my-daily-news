## 它是什么
olmOCR 是一个将 PDF 及图片文档转换为干净 Markdown 文本的工具包，服务于 LLM 预训练数据集的制作。它基于 7B 参数的视觉语言模型（VLM），通过页面截图推理生成线性化文本，输出自然阅读顺序的内容，并自动剔除页眉页脚。

## 为什么火
- **精准的行业痛点**：LLM 训练需要从海量 PDF 中提取高质量文本，传统 OCR 难以处理多栏、表格、公式和手写体。
- **标杆级 Benchmark**：开源了自己的评测套件 olmOCR-Bench（1400+ 文档，7000+ 测试用例），并在与 Mistral OCR、Marker、MinerU 等 8 款工具的对比中取得 82.4 的总分，处于一梯队。
- **成本极低**：每百万页转换成本不到 200 美元，适合大规模工业化处理。
- **实用生态**：提供在线演示、Docker 镜像、远程推理支持和训练代码，降低了使用和定制门槛。

## 技术栈
- **语言**：Python
- **推理引擎**：vLLM（曾用 sglang，后迁移）
- **模型**：基于 VLM（7B 参数），默认使用 FP8 量化以提升速度
- **系统依赖**：poppler-utils、微软字体包等
- **部署**：支持本地 GPU（12GB 显存起步）、远程 OpenAI 兼容 API、Beaker 集群和 Docker

## 核心能力
- **多格式输入**：PDF、PNG、JPEG
- **复杂版面还原**：公式、表格、手写体、多栏布局、插图旁文字
- **智能清理**：自动去除页眉页脚，输出自然阅读顺序的纯文本
- **高性能**：基准测试覆盖学术论文、老旧扫描件、多栏文档等场景，整体准确率领先于多数开源工具
- **可扩展**：提供完整的训练流水线和基准测试套件，方便二次开发

## 适用场景
- LLM 训练数据预处理（如从论文、报告、古籍中提取文本）
- 企业文档数字化、知识库构建
- 需要将非结构化 PDF 转为结构化 Markdown 的自动化流程
