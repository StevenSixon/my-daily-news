## 它是什么
Graphify 是一个将整个项目——代码、文档、SQL、图片甚至视频——自动转化为可查询知识图谱的 CLI 工具与 AI 助手技能。只需在 AI 编码助理中输入 `/graphify .`，即可生成可交互的 graph.html、分析报告和结构化 graph.json。

## 为什么火
- **极降低认知负荷**：不必在文件间盲目翻阅，图谱直接展示函数调用、类继承、数据流等关系。
- **广泛平台支持**：兼容 Claude Code、Codex、Cursor、Gemini CLI 等 20+ 主流 AI 编程环境，安装即用。
- **语言覆盖广**：内置 30+ 语言解析器（含树-sitter 驱动），甚至处理视频/PDF 等多模态内容。
- **社区活跃**：YC S26 项目，Star 数快速增长，版本迭代频繁（v0.9.5 修复大量回归问题）。

## 技术栈
- **核心**：Python 3.10+，tree-sitter 多语言解析，图分析（Leiden 社区检测可选）。
- **输出格式**：交互式 HTML、JSON 图数据、Markdown 报告；支持推送至 Neo4j、FalkorDB 等外部图数据库。
- **扩展性**：通过可选安装包支持 PDF、Office、视频转录、云端大模型推理（Ollama、OpenAI、Gemini 等）。

## 核心能力
- **一键图谱生成**：`graphify .` 即得图文件，包含节点（符号）和边（调用、继承、引用）。
- **增量更新**：支持 `--update` 仅处理变更文件，保留原有图结构。
- **高级查询与聚类**：可进行社区检测、跨文件间接调用解析。
- **多模态支持**：不限于代码，图像、视频、文档也能成为图的节点，实现全项目知识融合。
- **CI/CD 友好**：提供 Git hooks 自动更新图谱，便于代码审查。

## 适用场景
- **接手遗留系统**：快速理清复杂依赖关系。
- **AI 辅助开发**：让编码助手基于完整项目上下文提供更精准的建议。
- **技术文档自动生成**：导出架构图、数据流图。
- **多语言混合项目**：统一视角分析跨语言调用（如 Python 调用 SQL、Shell 脚本）。

## 同类对比
- 与 **Sourcegraph** 等代码搜索工具相比：Graphify 生成离线可计算图，支持语义聚类，而不仅是文本索引。
- 与 **CodeQL** 相比：更轻量，无需编写查询，图谱面向人类探索与 AI 消费。
- 与通用 **GraphRAG** 方案相比：专注于代码知识，解析精度更高（利用 tree-sitter），并直接嵌入 AI 助手工作流。
