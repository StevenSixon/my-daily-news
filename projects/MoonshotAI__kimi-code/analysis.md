## 它是什么
Kimi Code CLI 是 Moonshot AI 开源的终端 AI 编程代理，能读改代码、执行 Shell 命令、搜索文件、抓取网页，并根据反馈自主规划下一步。默认使用 Kimi 模型，也兼容其他供应商。

## 为什么火
上线不久即获 5.3k star，缘于**毫秒级 TUI 启动**、**单二进制分发**、独创的**视频输入**以及**子代理并行**。无需 Node.js 环境的安装方式和原生的 ACP 编辑器集成，大幅降低了开发者的引入成本。

## 技术栈
- 语言：TypeScript
- 构建：Node.js ≥24.15.0 + pnpm 10.33.0（仅开发时使用）
- 终端 UI：基于 pi-tui
- 分发：单二进制安装脚本，运行时不依赖 Node.js
- 协议：Agent Client Protocol (ACP) 用于 IDE 集成
- 模型后端：Kimi 模型，可配置兼容 OpenAI 接口的其他服务

## 核心能力
- **极速终端交互**：毫秒级启动的 TUI，专为长对话优化。
- **视频输入**：可上传屏幕录像或演示视频，代理能从中理解意图并生成代码、调整 LUT 等。
- **子代理并行**：内置 `coder`、`explore`、`plan` 子代理，在独立上下文中并发工作，主对话保持整洁。
- **MCP 对话式配置**：通过 `/mcp-config` 用自然语言添加 Model Context Protocol 服务器，无需手写 JSON。
- **插件生态**：从市场或 GitHub 安装技能与工具，信任级别透明展示。
- **生命周期钩子**：在工具调用、审批等节点插入自定义脚本，实现自动审计或通知。
- **编辑器集成**：通过 `kimi acp` 以 ACP 协议驱动 Zed、JetBrains 等 IDE。

## 适用场景
- 在终端内快速理解、修改或生成项目代码
- 将屏幕录像直接转化为脚本或过滤器
- 多步骤编码任务，拆分为并行子代理执行
- 将 AI 助手嵌入现有编辑器工作流

## 同类对比
相较于 Aider、Claude Code 等，Kimi Code CLI 的差异点在于**原生视频输入**、**单二进制零运行时摩擦**、**内置子代理模型**及**ACP 协议就绪**。但其他工具拥有更成熟的社区和插件生态，该项目仍处于快速迭代早期。
