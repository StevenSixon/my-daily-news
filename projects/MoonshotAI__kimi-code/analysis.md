## 它是什么
Kimi Code CLI 是 Moonshot AI 推出的终端内 AI 编程代理。它能读取和编辑代码、运行 shell 命令、搜索文件、抓取网页，并根据反馈自主选择下一步行动。默认支持 Kimi 模型，也可配置其他兼容提供商。以单二进制分发，无需 Node.js，安装即用。

## 为什么火
上线两个月即获 5000+ Star，直击开发者对轻量、快速、无环境依赖的终端 AI 编程工具的需求。独特的视频输入让代理“看懂”录屏生成代码，AI 原生 MCP 配置简化了工具集成；子代理并行工作保持主对话整洁；ACP 协议更让 Zed、JetBrains 等编辑器可直接驱动会话，覆盖日常编码到自动化全场景。

## 技术栈
TypeScript/Node.js（要求 Node ≥24.15，pnpm 10.33），TUI 基于 `pi-tui` 构建，采用 monorepo 管理。

## 核心能力
- **单二进制分发**：一条命令安装，无 Node.js 或全局模块冲突
- **极速启动**：TUI 毫秒响应，长期会话不显笨重
- **视频输入**：拖入录屏直接让代理“观看”，用于视频转代码、LUT 生成等
- **AI 原生 MCP 配置**：`/mcp-config` 会话式管理 MCP 服务器，无需手写 JSON
- **插件市场**：安装技能、MCP 服务、数据源，每个插件信任等级前置展示
- **子代理**：内置 `coder`、`explore`、`plan` 子代理，并行处理任务，主对话保持清爽
- **生命周期钩子**：在关键节点运行本地命令，控制风险、审计或自动化
- **编辑器/IDE 集成**：支持 ACP 协议，直接由 Zed、JetBrains 等驱动 `kimi acp` 会话

## 适用场景
- 终端内快速代码审查、重构、文档生成
- 从视频原型生成代码或处理多媒体任务
- 多步骤自动化流程，利用子代理并行探索与实施
- 在 Zed 或 JetBrains 中直接调用，无需离开 IDE
- 服务器环境零依赖部署

## 同类对比
类似 Claude Code、Aider 等终端 AI 编程工具，但 Kimi Code 的差异化在于：
- 真正零依赖安装，启动速度领先
- 视频输入是独家功能
- MCP 配置更人员友好，AI 引导完成
- 原生 ACP 协议让多编辑器集成更标准
- 子代理体系提供了更好的任务隔离与并行能力
潜在弱点是默认模型依赖 Kimi，但已支持配置其他端点。
