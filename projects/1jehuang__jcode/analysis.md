## 它是什么
jcode 是一个用 Rust 编写的新一代编码 Agent 控制框架，定位为“最智能的代码代理 harness”。它提供内置的记忆系统、多会话并发能力、侧边面板 UI，并极度强调性能与资源效率，目标是为高级开发者提升技能天花板。

## 为什么火
项目上线不足一年已获1.1万星，关键在于它直击现有编码 Agent 工具的痛点：内存膨胀和启动缓慢。通过 Rust 原生实现，jcode 实现了 14 ms 首帧渲染、单会话仅 27 MB 内存的超轻量表现，多会话叠加成本极低，对比 Claude Code、Copilot CLI 等有数量级优势。其创新的语义记忆和侧面板实时交互设计也吸引尝鲜者。

## 技术栈
- **语言**：Rust（纯原生，极致性能）
- **架构**：多会话客户端，支持本地嵌入（可关闭以进一步降低内存）
- **LLM 集成**：支持 OpenAI、Anthropic、AWS Bedrock 等多种提供商，通过 MCP 协议扩展
- **UI**：自研 TUI，支持 Mermaid 图表渲染、侧面板、Diff 展示
- **内存系统**：基于语义向量的自动记忆提取与检索，带记忆图与侧代理验证

## 核心能力
- **极致性能**：首帧最快 14 ms，单会话 PSS 27.8 MB，10 会话仅 260.8 MB，边际成本极低
- **自主记忆**：对话轮次自动向量化并建立相似度索引，被动/主动触发检索，支持记忆合并与冲突检测
- **多会话工作流**：同时管理多个独立会话，内存和资源高度隔离
- **丰富的 TUI**：侧边面板、内联图表、自定义快捷键、文件实时更新
- **插件化工具调用**：支持 MCP、浏览器交互等外部工具
- **跨平台**：覆盖 Linux、macOS、Windows 全架构

## 适用场景
- 同时处理多个代码库的专业开发者
- 需要长时间运行、跨任务累积知识的 AI 编程环境
- 对资源极度敏感的服务器或嵌入式开发场景
- 希望定制编码 Agent 工作流的极客用户

## 同类对比
与 Codex CLI、Claude Code、Cursor Agent 等相比，jcode 在启动速度和内存占用上有压倒性优势（见 README 性能表格），尤其在多会话场景下优势成倍放大。但它放弃部分豪华 UI 或生态绑定，定位更像一个可嵌入的底层框架而非全功能 IDE 插件。
