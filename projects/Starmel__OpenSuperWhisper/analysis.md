## 它是什么
OpenSuperWhisper 是一款 macOS 原生听写应用，使用 Whisper 或 Parakeet 模型在本地将语音转为文字。支持录音实时转写、拖拽音频文件批量转录、全局快捷键、鼠标按键触发、按住说话等交互。完全基于 Apple Silicon（ARM64）运行，最低系统要求 macOS 14。

## 为什么火
与商业听写工具相比，它完全本地运行，无隐私顾虑；与同类开源项目（如 Buzz、MacWhisper）相比，原生感更强、交互更灵活（支持单修饰键长按录音、鼠标侧键触发），且内置双引擎可直接下载模型，省去自行编译的痛苦。对于追求效率的极客，它把“语音速记”做到了开箱即用。

## 技术栈
- 语言：Swift
- 推理引擎：whisper.cpp（C++）、Parakeet（Rust，通过 FluidAudio）
- 构建工具：brew + cmake + libomp + Rust + Ruby，CI 使用 GitHub Actions
- 模型：应用内直接下载 Whisper ggml 格式模型，也支持手动放置 .bin 文件

## 核心能力
- 全局快捷键：可绑定组合键、单修饰键（左Cmd、右Opt、Fn）或鼠标按键（中键/侧键）
- 录音模式：按住录音（释放即停止）或点击切换录音
- 转录引擎切换：在 Whisper 与 Parakeet 间选择，模型在 app 内下载
- 音频文件转录：拖放音频文件或通过 Finder 右键/双击打开，支持队列处理
- 语言自动检测，日语/中文/韩语自动更正
- 菜单栏控制麦克风切换（内置、外接、蓝牙、iPhone 连续互通）

## 适用场景
- 会议、访谈快速文字记录（本地离线，无网络要求）
- 灵感速记：用全局快捷键快速口述并转文
- 辅助输入：替代键盘输入长文，配合自动纠正提升准确度
- 批量音频转文字：拖放录音文件自动转录

## 同类对比
| 特征 | OpenSuperWhisper | MacWhisper | Buzz | SuperWhisper（商业） |
|------|------------------|------------|------|----------------------|
| 模型本地运行 | ✅ | ✅ | ✅ | ❓（在线） |
| 全局快捷键 | ✅ 修饰键/鼠标 | ❌ | ❌ | 有限 |
| 双引擎 | ✅ Whisper+Parakeet | ❌ | ❌ | ❌ |
| 音频文件批处理 | ✅ 拖放+队列 | ✅ | ✅ | ❌ |
| 完全免费开源 | ✅（MIT） | ❌（部分闭源） | ✅ | ❌ |

OpenSuperWhisper 在交互自由度（单键长按、鼠标）和引擎切换上优势明显，但部分基础功能仍缺失（如流式转录）。
