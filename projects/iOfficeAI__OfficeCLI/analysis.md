## 它是什么
OfficeCLI 是一个专为 AI 智能体设计的命令行 Office 套件，支持全创建、全读取、全修改 Word/Excel/PowerPoint。它提供跨平台单一二进制，无需安装或依赖 Microsoft Office。内置 HTML/PNG 渲染引擎，让 AI 模型能“看见”文档原貌，实现渲染-观察-修复的闭环。

## 为什么火
AI Agent 生态爆发，但操作 Office 文档一直是空白地带：传统库门槛高、商业 API 有延迟/成本、本地 LibreOffice 笨重。OfficeCLI 以一行 `curl` 安装技能文件的方式，直接嵌入 Claude Code、Cursor 等主流 agent 工具，让 AI 获得原生 Office 操作能力。GitHub star 在短短 4 个月内突破 1.1 万，印证了市场需求。

## 技术栈
主要语言：C#。发布为跨平台原生二进制（Windows/macOS/Linux），无外部运行时依赖。自研文档解析与渲染引擎，支持 `.docx`/`.xlsx`/`.pptx` 到 HTML/PNG 的高保真转换。CLI 提供路径选择器（如 `/slide[1]/shape[1]`）的编排语法，通过标准输入输出与任意 Agent 进程交互。

## 核心能力
- **全格式创建/读取/修改**：Word、Excel、PPT 均支持从零创建、读写任意元素、重组文档结构。
- **渲染反馈**：`view html` 或 `watch` 实时预览，形成 agent 的“视觉”校对。
- **深度 Word 能力**：RTL/多语言（含字体、语言标记、古尔邦文编号）、段落/表格/文本框/形状/图片/公式（LaTeX 输入）、Mermaid 图表、注释、脚注、水印、域代码、修订跟踪、内容控件等。
- **深度 Excel 能力**：350+ 函数含动态数组、公式自动重写、透视表（含日期分组、计算字段、切片器）、条件格式、排序、数据验证、迷你图、命名区域、表格、图表（含箱线图、帕累托图）、布尔组合选择器（`row[Salary>5000 and Region=EMEA]`）。
- **PowerPoint 能力**：幻灯片增删，形状操作（图案填充、模糊效果、超链接、高亮）、幻灯片编号/页眉页脚。
- **Agent 友好**：结构化 JSON 输出、批量操作、路径表达式、无需代码即可被 LLM 准确调用。

## 适用场景
- AI 辅助的自动报告生成（财务、销售、学术）。
- 批量文档提取与转换（例如从 DB 生成 Word/Excel）。
- 在编程 Agent （Claude Code、Aider）中直接处理 Office 附件。
- 无需桌面环境的文档自动化流水线。
- 本地隐私敏感场景，所有操作离线完成。

## 同类对比
| 方案 | 安装复杂度 | AI 友好度 | 视觉反馈 | 全格式覆盖 | 本地运行 |
|------|-----------|----------|---------|-----------|--------|
| python‑pptx / openpyxl | 需 Python 环境，多库组合 | 低（需编程序列） | 无内建渲染 | 分散 | 是 |
| unoconv / LibreOffice | 数百 MB 依赖，启动慢 | 中 | 可导出 PDF | 全 | 是 |
| 商业 API (Google Docs, Office365) | 网络依赖，密钥管理 | 中 | 有限 | 部分 | 否 |
| OfficeCLI | 单二进制，零依赖 | 高（CLI 原语为 agent 设计） | HTML/PNG 即时渲染 | Word/Excel/PPT | 是 |

OfficeCLI 在“Agent 原生适配”和“零安装”上形成显著优势，尤其适合需要闭环验证的高质量文档任务。
