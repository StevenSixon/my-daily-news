## 它是什么
SkillSpec 是一个 Rust 编写的 CLI 工具，为 AI Agent 的技能（通常以 SKILL.md 文档形式存在）增加结构化契约层。它通过 `skillspec doctor` 命令分析技能文档的“可跟随性”风险，生成风险报告；通过 `skillspec import` 将现有技能转换为带路由、规则、依赖、检查点的 `skill.spec.yml` 契约；并提供运行后的对齐摘要，让每次技能执行都可审计。

## 为什么火
当前 Agent 技能几乎全部依赖纯文本说明，模型可能跳过安全规则、使用未声明工具、无凭据地宣称完成。SkillSpec 提供了一种无侵入的解决方案：不改变 Agent 运行时，只需一个配置文件和一条命令，就能从“靠运气”变成“有证据”。首发即获 698 Star，说明社区对技能可靠性的焦虑和需求。

## 技术栈
- 语言：Rust（CLI 及核心库）
- 契约模型：Rust 类型定义 + JSON Schema + 参考语法
- 测试：自带一致性测试套件
- 集成：支持 Claude Code、Codex 等 Agent 平台插件安装
- 发布：预编译二进制（macOS/Linux/Windows）+ Cargo 安装

## 核心能力
- **风险诊断（Doctor）**：分析 SKILL.md 的上下文位置效应、buried obligations、未声明依赖、缺失测试/进度记录等，给出“Agent 偏离风险”评分
- **契约导入（Import）**：将 prose 技能转化为包含路由、规则、禁止操作、依赖、检查点、测试和证明期望的 spec.yml
- **运行证明（Prove）**：每次执行可产出对齐摘要，记录所选路由、已完成步骤、缺失证明、禁止操作状态、token 用量等
- **路由模式（Router）**：当技能列表过长时，动态选择唯一技能，避免 harness 发现能力下降
- **托管 Doctor 页面**：无需安装即可粘贴公开技能 URL 查看风险报告

## 适用场景
- 构建多技能 Agent 应用的开发者，需要确保每个技能可被模型可靠执行
- 团队协作中，需要在 PR 中附带技能风险基准和导入后的对齐证明
- 希望将技能作为可审查工件而非纯文本的 AI 工程实践
- 技能库规模大，需要路由避免发现瓶颈的场景

## 同类对比
与 Orchestration 平台（如 LangChain、CrewAI）不同，SkillSpec 不是 Agent 运行时，而是技能层的静态分析和契约工具。与纯评估框架相比，它更侧重将评估转化为可执行的合约并记录运行证据。无同类工具直接竞争，填补了“技能文档可靠性”的空白。

## ℹ️ 置信度与信息盲区

- 置信度：**high**
- 信息盲区：未提供与其他技能验证方法的定量对比基准；未说明大规模技能库（如 100+ 技能）下的路由/诊断性能；没有提及对非 GitHub 托管私有仓库的本地化 CI 集成细节
