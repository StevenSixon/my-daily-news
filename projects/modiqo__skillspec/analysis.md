## 它是什么
SkillSpec 是一个 Rust 编写的 CLI 工具，用于分析和改进 AI Agent 的技能描述文件（SKILL.md）。它通过一个名为 Doctor 的命令评估技能被 Agent 遵循的风险，并可将自然语言技能转换为结构化的 YAML 合同（skill.spec.yml），提供编译后的轻量加载器，以及运行后的对齐证明记录。不替代任何 Agent 运行时，仅作为技能层的补充。

## 为什么火
在 Agent 开发中，很多技能文档冗长且关键规则容易被模型忽略，导致执行不可靠。SkillSpec 通过量化风险（如上下文负载、义务位置、未声明依赖）给出 0-100 分，帮助开发者快速发现问题。自发布以来迅速获得 873 星，得益于其轻量化设计（不绑定特定编排平台）和可与 Claude Code、Codex 等集成。它还提供在线 Doctor 页面，方便社区快速审查公开技能。

## 技术栈
- Rust 编写，发布为跨平台二进制（Linux, macOS, Windows）
- CLI 通过 curl 一键安装或 Cargo 安装
- 合同建模使用 Rust 类型、JSON Schema、参考语法，并有 conformance suite
- 支持与 Claude Code、Codex、Agents 等通过插件市场集成
- 包含 Rote 集成，可捕获执行轨迹生成技能（但详细实现未公开）

## 核心能力
1. **风险评估** (`skillspec doctor`)：分析 SKILL.md 的上下文过载、规则位置、依赖声明等，计算 Agent 遵循风险分数，并指出可能后果。
2. **结构化导入** (`/skillspec import`)：将自然语言技能转为 skill.spec.yml，包括路由、规则、禁止动作、依赖、检查、测试和证明预期，并编译轻量加载器。
3. **路由模式**：当技能库过大时，通过 router 模式仅暴露相关技能，避免 Harness 列出过多技能。
4. **运行证明**：每次执行后可输出对齐摘要，包含所选路由、完成步骤、缺失证明、禁止动作状态、令牌用量等，实现可审计性。
5. **公共审查**：提供在线 Doctor 界面和 GitHub Action，可对公共技能仓库生成风险报告。

## 适用场景
- 开发多个独立技能的 Agent 系统，需要确保每个技能被可靠执行
- 团队间共享技能时，通过合同和审计记录保证一致性
- 在 PR 中集成 Doctor 报告，作为技能引入的门禁
- 需要降低大技能文件上下文窗口损失风险的项目

## 同类对比
- 与其他 Agent 框架（如 LangChain、AutoGPT）不同，SkillSpec 不触及运行时或编排层，仅聚焦技能本身的规范性与可观测性，因此可与任何框架共存。
- 与单纯的技能模板（如 OpenAPI 风格的 skill definition）相比，它提供了风险评估引擎和运行期验证记录，而非只是描述格式。
- 与监控工具（如 agent 执行日志）相比，它主动分析技能质量并生成合同，预防问题而非事后排查。
